先认识两个不同的对象

Operator源工程设置作用
Position ObjectGeoSphere001决定粒子从哪个对象的位置分布生成。
Shape InstanceGeoSphere002 · Scale 100%决定每一颗粒子看起来是什么形状。它不是发射位置。
BirthEmit Start −5 · Emit Stop −5 · Amount 120在 −5 帧一次生成 120 颗，因此 0 帧已经能看到粒子。
SpeedSpeed 0 · Variation 0这个操作器没有给粒子初始移动速度；模型缩放等变化仍可发生。
Split AmountEvery Nth = 2每隔一颗分流，送入另一条事件路径。
Material StaticAssigned Material = Fog把源工程的 Fog 材质指定给粒子。

跟着操作：只改一个值

  1. 打开学习副本，按 6。
  2. 在 Event 001 中点 Birth / 出生 001，确认 Amount 为 120。
  3. 把 Amount 改成 30，回到时间轴起点再播放。颗粒数量应该减少。
  4. 恢复 Amount = 120。点 Speed / 速度 001，先只观察 Speed = 0。
  5. 点 Shape Instance / 图形实例 001，核对拾取对象是 GeoSphere002。不要把它与 Position Object 中的 GeoSphere001 混淆。

上面是基于实际源工程设计的学习实验，不冒充教师在原片里的逐秒操作顺序。按同一顺序重新打开文件即可恢复原值。

Open and reproduce

从零完整路线

先按这八个模块走通一遍，再选择下方对应课程。每一步有操作、用途和验收点。

01 从空场景开始：单位、视口和保存

  1. File → Save As另存工作文件，再创建新场景。不要把练习直接覆盖到原工程。建议每个效果独立目录，使用01_setup、02_shape、03_material、04_animation版本。

    用途：能回到上一个正确阶段，排查材质和动画时不用重做。

  2. Customize → Units Setup设Metric/Centimeters；System Unit Setup中1 Unit=1 Centimeter。显示单位和系统单位是两个设置。补充练习统一厘米。

    用途：Noise的Object/World尺寸、灯光衰减和模型大小才有一致尺度。

  3. Top看平面摆放，Front/Left看高度，Perspective看构图。选中目标再按Z缩放到选择；Alt+W最大化当前视口。不要把透视视口误认为已经存在Camera对象。

    用途：先在正交视图解决位置，再在透视图检查遮挡。

  4. 选择Move，在Reference Coordinate System选World。通过Transform Type-In输入X/Y/Z；移动和缩放输入框不是同一组数据。

    用途：防止把本地轴、百分比缩放误抄成位置或尺寸。

  5. Time Configuration设置0–100帧、30fps作为补充练习；只有原片明确显示的帧率才称老师设置。关键帧单位是Max帧，不是视频秒数。

    用途：课程视频的00:30与Max第30帧不是一回事。

检查点：建立一个Box并移动到(0,0,0)，四视口都能定位它；保存一次后再继续。

02 搭建场内：地面、弧形背景和比较物体

  1. 第一套视频从单个Cylinder开始；第二套多个片段已带有Loft001或Room。原片没有展示的舞台建造过程，以下作为补充方法，不冒充老师的逐步操作。

    用途：理解继承场景的边界，避免照着材质步骤却缺地面、灯和背景。

  2. 在Left视图用Shapes → Line画开放折线：地面起点Y=-600/Z=0，拐角Y=600/Z=0，墙顶Y=600/Z=800。X放在-800。进入Vertex，给地面与墙的拐角Fillet=200。

    用途：平滑圆角去掉地面与墙的尖锐折线，方便看投影和反射。此尺寸为补充练习值。

  3. 给开放截面加Extrude，沿左右方向铺满1600cm，使X范围为-800..800。检查法线朝向场内；若方向错误，修正Extrude方向或面法线。提供的10号工程用等价的分段曲面搭建，便于直接检查。

    用途：得到地面到后墙连续的摄影棚背景。

  4. 先放三个半径75球：中心(-170,0,75)、(0,0,75)、(170,0,75)。左球金属、中球暗色、右球做发光材质；这些是补充练习布局。

    用途：同一灯光下比较反射、漫反射与自发光，避免把照明效果误认为材质参数。

  5. 按Room、Effect、Lights、Cameras分层或命名；保持效果模型单独可选。隐藏对象和冻结对象含义不同，渲染前检查对象是否被排除或关闭Renderable。

    用途：选择不会混乱，也能隔离判断是哪一层造成黑屏。

检查点：先只给全部对象赋灰色Arnold材质，从透视视口看见地面、后墙和三个完整球，再进入灯光步骤。

03 放镜头：透视视口、实体相机和构图

  1. v01–v07主要使用透视视口和/viewport_camera渲染；那是当前视角，不是场景里已经放了实体相机。要固定构图或复现后续相机实验，才建立实体Camera。

    用途：避免找一个原片根本没有创建的镜头。

  2. 先把Perspective视口调整到合适构图，保持该视口激活，再用Views → Create Physical Camera From View（默认Ctrl+C）。Ctrl+C在这里不是复制模型。

    用途：快速把满意的临时视角固定成物理相机。

  3. Target相机可以分别移动相机和Target；Free相机只有本体，需要旋转朝向。提供的早期独立效果工程是Free Camera，自选look-at点只是计算朝向用，并没有可选的Target对象。

    用途：不要以为只输入位置就会自动看向模型。

  4. 补充舞台相机示例位置(375.779,-699.973,268.641)，朝向(0,0,120)。位置来自v09某个实验时点，看向点由本练习补齐，两者不称原片最终组合。使用Target相机时把Target移动到看向点；Free则调整旋转或使用提供的定位脚本。

    用途：把相机位置和视线分开设置，才能真正把对象纳入画面。

  5. Physical Camera：Film Width36mm，Specify FOV开启，FOV45°，F-number8，景深关闭用于清楚检查。FOV越小看到的范围越窄；不能同时强求FOV和某个焦距独立固定，二者受片幅、焦距、对焦等共同影响。

    用途：相机位置决定透视关系，FOV决定取景宽度；不要只靠一个Zoom把两者混为一谈。

  6. 把球保持不动：先只前后移动相机，观察球与背景的相对大小；再固定相机只改变FOV。v09后段就是这种透视实验，应分别记录每个时点，不能把不同时间的相机和Target拼成一组参数。

    用途：理解为什么同样让主球铺满画面，背景看起来仍然不一样。

  7. 激活视口按C或用视口标签Cameras选择相机；Shift+F看安全框，再确认Render Setup的View to Render。保留画面边缘余量，尤其动画最大缩放时。

    用途：相机建好了但渲染还是旧透视视口，是常见的“镜头无效”。

检查点：画面能看到完整效果主体；拖到动画最高、最宽和结束时刻，主体都没有意外被裁切。

04 放灯与投影：先照明，再实验

  1. 给地面和球临时赋Arnold Standard Surface，Base约.8、Emission0。创建Arnold Quad，补充位置(-250,-150,500)，朝向(0,0,100)。

    用途：自发光材质即使没灯也能显示，不能用它验证场景照明是否正确。

  2. v04早段Quad为100×100、Spread1、Intensity500、Exposure6；这些是该时点值。不要把v07早段200强度与v04的500混成全课程通用设置。

    用途：面积控制柔和程度，Intensity和Exposure共同影响亮度。

  3. 在Top调左右/前后，Front调高度。目标或朝向要落到承接面与主体附近，先关复杂贴图渲染一张，再加入Noise。

    用途：如果无贴图时都不亮，先修位置、方向或曝光，不要继续堆节点。

  4. Photometric Light选Spotlight分布，开启Projector并连接Noise。课堂还有柱形光源Length520/Radius13、1500cd的独立实验；这不是Arnold Mesh Light。

    用途：光度学柱形灯、实体圆柱、Arnold网格灯是三个不同对象/概念。

  5. 打开灯的Exclude/Include窗口，选择目标对象，确认当前模式是Exclude还是Include，以及影响Illumination、Shadow或二者。先只改一个对象，再渲染对比。

    用途：不受灯影响与不投影不是同一种状态；错误排除会让某个球意外变黑。

  6. 先建实体Cylinder（课堂Radius28.399/Height291.01/12边/段1），横向放置；再创建Arnold Light，Shape选Mesh，Mesh槽指定该圆柱。后续读值Intensity1/Exposure2，并使用Noise颜色纹理。

    用途：普通圆柱不会因为看起来像灯管就发光；必须建立灯到网格的引用。

  7. Arnold Spot上添加Gobo修改器，Slide Map连接Color Correction→Noise。滤镜Replace、Density0、Scale1/1、Periodic。先检查灯照到平面，再调Noise颜色与Gain/Gamma。

    用途：Gobo控制投射图案，和把同一纹理贴在球表面不同。

检查点：关掉贴图时有稳定照明；打开贴图后图案同时影响承接面和物体；排除测试能产生可解释的变化。

05 材质搭建：从灰度形状到完整颜色

  1. M打开材质编辑器，创建Arnold → Surface → Standard Surface并赋给正确模型。发光练习Base0、Specular0、Emission1，先用纯白发光。

    用途：确认模型、赋材质和镜头正确后，再加入复杂贴图。

  2. Cellular/Noise/Gradient先接Emission Color，看到黑白纹理；检查Explicit Map Channel1与Object/World XYZ是否匹配。

    用途：无UV的模型使用显式UV会变成常量或错误纹理；尺寸差几个数量级也会变成细噪点。

  3. Mapped Gradient按源亮度重映射，Solid产生硬阈值；W角90°的线性Gradient用于高度范围。逐个查看节点输出。

    用途：把“纹理形状”和“它出现在哪一段高度”分开控制。

  4. 将形状遮罩接Opacity。黑=不可见，白=可见，灰=半透明；黑色Emission本身并不会删除几何。

    用途：颜色分支与透明分支职责不同，整片矩形/圆筒残留通常从Opacity检查。

  5. 参考每课证据设置色标和Composite模式；火焰Darken/Soft Light、紫金球Screen/Lighten、气流Color不能全替换成Multiply。

    用途：相同两张贴图，混合模式改变会直接改变形状或配色。

  6. 色标条场景RGB(0–255)与颜色选择器的显示RGB/HEX不同。输入哪组值要看字段标注；网站将两者分开，不能直接混抄。

    用途：避免数值看似一致但渲染偏色。

检查点：暂时断开Opacity仍能看见整个发光模型；接回后只剩期望图案。节点数值与各课截图或明确补齐表对应。

06 动画：物体、修改器、贴图分别控制

  1. Position/Scale改变几何；Noise Modifier改变几何形状；Noise贴图Phase/Offset只改变采样。三种动画不能互相冒充。

    用途：气流不只是条纹移动，v11还对圆筒做Z方向缩放，并给Ball加Noise修改器。

  2. 先关闭Auto Key设置初始状态；到起始帧打开Auto Key并记录需要的属性，再到目标帧输入终值，最后关闭Auto Key。确认轨道上真的出现键。

    用途：避免无意中把相机、灯或模型位置也打上关键帧。

  3. 在Curve Editor定位对象与具体轨道（Position Z、Scale Z或贴图参数）。检查横轴帧数和纵轴值，先记录键的数值，再处理切线。

    用途：曲线看起来相似不代表时间和值相同；没显示的切线长度只能标补齐。

  4. Ball的Noise修改器：Seed0、Scale100、Fractal开、Roughness0、Iterations6、Strength20/20/0；Animate Noise开、Frequency.25。45帧Phase45是课堂采样值。

    用途：XY扰动使球体轮廓变化，Z强度0不增加竖向扰动；不等于Noise贴图Size。

  5. 气流Color Correction颜色在15帧黑、30帧白、70帧黑。先检查这些帧再调中间曲线；第0帧看不见可以是预期，不等于文件坏了。

    用途：用明确的出现/峰值/消失三个时刻验收动画。

  6. v10前半段Ball Z在前约50帧接近0，后段向上；原片并非证据充分的“从高处落地”。旧08工程的下落/压扁是创作补齐，单独保留说明。

    用途：把老师演示与自己的扩展动作分开学习。

检查点：逐帧检查开始、峰值、结束；几何变形和贴图流动分别单独播放，最后再一起播放。

07 渲染与导出：先单帧，再序列

  1. Render Setup → Assign Renderer选择Arnold；本机旧Composite/Gobo练习使用CPU兼容路径。CPU不是灯光或相机坏了；不要只因GPU空闲就改一组未验证的节点。

    用途：本机版本的兼容性优先于硬件占用率。

  2. 单独工程建议圆柱40、火焰35、气流30、冲击创作版42帧。确认View to Render为所需视口/Camera，再渲染一张。

    用途：先排除开始帧透明度0造成的黑画面。

  3. 补充练习640×480，Arnold Camera AA3；动画预览可先320×240或480×360、AA2。课堂v10曾输出0–100共101帧、320×240、CPU到AVI。

    用途：先验证构图和运动，再增加分辨率与采样。

  4. Common → Time Output选择Active Time Segment或Range；设置保存路径。实际制作优先逐帧PNG/TGA等序列，单帧失败可补渲染。课堂AVI是其演示选择，不要求你必须使用同一种格式。

    用途：工程帧数、输出帧率和播放速度要一致。

  5. 若用于合成，选择支持Alpha的格式，并明确渲染背景与透明通道用途。网页在黑底显示发光预览；不能只看图片查看器默认白底就判断颜色错误。

    用途：黑色背景与真正的Alpha透明是不同数据。

  6. 保存.max及材质库；外部贴图用Asset Tracking检查路径，必要时归档。打开另一份副本检查材质、相机和关键帧。

    用途：能在当前会话渲染，不代表重新打开或拷贝后仍然完整。

检查点：一张静帧构图正确，一段序列确实有运动且结束状态正确；重新打开文件后手动定位可见帧仍能复现。

08 常见失败：按顺序排查

  1. 依次查：当前帧是否全透明 → 模型是否Renderable → View to Render是否正确 → 镜头是否朝向主体 → 无灯时Base材质是否本来就黑 → 曝光。

    用途：一次只改变一个条件，不要用提高Emission掩盖镜头错误。

  2. 断开颜色干扰，只检查Opacity是否连接、map开关是否开启、遮罩是否有黑白变化、UV通道是否存在。

    用途：颜色里有图案不等于几何已被透明裁切。

  3. 先关Gobo/Projector看普通照明；再查灯类型、滤镜挂在哪盏灯、Noise坐标/尺寸、对象是否被Exclude。

    用途：把“没照到”与“纹理没变化”拆开排查。

  4. 确认不是仅拖动视频播放器；在Max时间滑块检查实际键。材质Phase键与模型Scale键分别查看。

    用途：视频时间轴与3D场景时间轴不同。

  5. 先对照同一时点、相同相机或视口、曝光与材质类别；再看网站差异栏中的补齐值。不要把不同时点实验值混成最终参数。

    用途：课程中的试错过程本身需要保留，不能全部浓缩成一个“最终值”。

检查点：能说清问题出在几何、相机、灯光、材质、动画或输出中的哪一层，再修改对应参数。

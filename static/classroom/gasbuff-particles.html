Follow the event

按6打开Particle View。PF Source连接Buff_Rising_Particles事件，其中依次是Birth → Position Icon → Speed → Shape Instance → Material Static → Delete → Display。

  1. Birth控制“何时出生、出生多少”，Delete控制“出生后活多久”。停止发射并不代表现有粒子立即消失。
  2. Speed控制运动，不是移动整个PF Source。改变Divergence会让方向散开，Variation改变每颗速度。
  3. Shape Instance指定参考GeoSphere；Material Static指定Arnold材质。参考球本身不参与渲染，但粒子仍用它的形状。
  4. Display选Geometry才能在视口看到实体形状；视口显示与最终渲染要分别检查。

气 Buff：保留斜纹的周期 UV 修复实验

03版另存自02光晕动画工程。粒子、模型、镜头、Bloom和原Channel1不变；只为圆柱条纹增加独立Channel2。35、45、60帧已分别渲染修复前后对照。该方案是补充修复，不是老师逐值设置；03完整动画已输出，详见下方版本交付小节；该动画仍使用旧Scale估算值。

为什么不是加面数或补洞？

此前检查已确认圆柱侧面几何闭合，UV绕一圈则从约-0.015625跳到0.984375，相差1。这种UV边界本身正常；但条纹经W Angle30°旋转后，两端可能落在不同的渐变位置。仅把U Tiling设为整数，并不能保证旋转后的图案接上。

这版怎么设置

位置设置作用
模型 Map Channel1保留原UV继续供Height Fade和颜色使用
模型 Map Channel2U2=U1−0.625×V1，V2=V1把UV向左倾斜形成斜纹；上圈比下圈左移0.625个U单位
Stripe / CoordinatesMap Channel2，U Tiling4，V Tiling1绕一圈跨过4个渐变区间
Stripe / CoordinatesW Angle0°，U Mirror On，U Tile Off不再用旋转制造斜纹；相邻两段镜像构成一个完整周期

U两端相差1，乘U Tiling4后相差4；Mirror图案每2段回到同一方向，因此两端跨过2个完整周期。保存重开后已检查UV边界的相位差为4，原Channel1和基础模型顶点未改变。此数学条件只覆盖条纹坐标，不自动证明整个材质或全部动画都无缝。

自己检查工程

  1. 打开03版，选择Cylinder001，在副本上加Unwrap UVW并选择Map Channel2，查看倾斜的UV；Channel1仍为原坐标。
  2. 按M找到圆柱Opacity Composite的第一层Stripe，检查上表参数。Emission Color使用同一个Stripe实例，所以轮廓与颜色条纹一起改变。
  3. 固定Frame45和同一个Camera，对照下图。不要同时修改Exposure、Emission或Bloom，否则不能判断UV修改的影响。
  4. 斜向来自Channel2形状，重复密度来自U Tiling。随意把4改成奇数时，Mirror的左右方向未必接回；修改后必须重新检查边界。

0.625和4都是本次设计值，条纹密度与原版略有不同。第一轮正向倾斜使螺旋反向，已通过同帧渲染发现并改为负向；那个候选没有替换这里的交付文件。

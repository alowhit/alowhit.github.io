这节课换成 Cellular 水面，然后把上一节的线性条纹少量混回来。先学灰度图案，再学蓝色映射，最后加动画。以下数值来自本机 [本机资料路径] 的实际读取；它是包含后续水滴的保存版本，不代表视频每个中间时刻。

原工程未修改，SHA-256 前后相同。学习副本已通过 Max 的 Save As 保存。下方另有水面观察镜头副本和三帧渲染。水面 101 帧已完成；雨滴考核仍未完成。

1 · Create the surface

Plane 名称 Wave，Length / Width = 400 cm，Length Segs / Width Segs = 1 / 1，Z = 5 cm。保留 Generate Mapping Coords。源场景还有 LightRoom、两个 Arnold Lights 和 Sphere001 水滴；没有保存 Camera 对象，不能声称恢复了老师镜头。

2 · Make the cell pattern

在 Slate 创建 Cellular #36，复制为 #37。两者 Size = 0.2，Spread = 0.5，Fractal = Off，Coordinates 使用 Explicit Map Channel 1。#37 的 Offset = (0.5, 0.5, 0.2)，W Angle = 90°（Frame 0）。黑色中心和亮边界形成不规则区域。两个方向叠加，使水面不只是一排重复图案。

3 · Composite #38

LayerMapBlend ModeOpacity
1Cellular #36Normal100%

Smoke #39 使用 Explicit Map Channel 1、Size 0.2、Iterations 5、Exponent 1.5。Multiply 层把部分区域压暗。练习时先关闭 Auto Key，把这一层 Opacity 改为 0，观察差异，然后恢复 70。

4 · Add fine details

Noise #40 → Source Map of Gradient Ramp #41。#41 用 Mapped，把 Noise 的灰度重新分配为多条明暗带。源工程保存的 #41 Noise Amount 是 0.12，Size = 0.8；视频中途出现的 0.1 不等于最后保存值。

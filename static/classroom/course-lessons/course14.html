Shape Instance · two different objects

已检查 82 张、约每 20 秒一张的画面，并核对以下 16 张原分辨率截图。前半段演示速度、方向和内置形状；后半段重新建立球面粒子。没有把前后两段拼成同一个最终场景。

Follow the second setup

  1. Create GeoSphere001，Radius 30 cm，Segments 2，Icosa，位置 [0,0,50]。
  2. Position Object 的 Emitter Objects 选择 GeoSphere001。它用来安排粒子的出生位置。
  3. 老师后续将粒子安排到球的顶点，显示 Total 42。已补查：Location = All Vertices；Birth Start = Stop = −1，Amount 42；Speed 0。
  4. Display 设 Geometry，先观察 Cube 粒子。
  5. 另建 GeoSphere002，然后用 Shape Instance 替换 Shape。在 Particle Geometry Object 中选 GeoSphere002。
  6. Scale 150%，Variation 50% 是本片结尾可见值。GeoSphere002 Radius 10.0 cm，Segments 2，Icosa，已从 24:20 画面确认。

Scale 150%：每颗粒子以参考模型为基础放大。Variation 50%：让颗粒大小不一致。Animated Shape：是否持续读取参考模型的形变动画；本片结尾未开启。我们另做的雨滴练习开启了它，属于补充内容。

自己动手

  1. 分别打开三个工程，按6找到Trial_Speed，对照表格核对。
  2. 回到0帧，再拖到30帧。若Geometry立方体遮住运动分布，可将Display改成Crosses。
  3. 在03_NarrowCone里只把Divergence从20改为0，回0帧再播放：粒子方向应该收拢。恢复20，再只把Variation从5改为0，比较同龄粒子的距离。
  4. 这些是独立试验状态，不是把三个Speed堆在同一事件里。改值前可另存练习副本。

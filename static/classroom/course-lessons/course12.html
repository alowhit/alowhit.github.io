Smoke × Stripes：让条纹不再整齐

本节已完成Smoke叠加的原生MAX和实际Arnold渲染，并重新打开检查参数。后面的Color Correction、橙色材质及底部烟雾还未完成。当前偏暗画面用于检查贴图变化，不是老师最终效果。

操作顺序

  1. 保留上一课两张Gradient Ramp和外层Composite。
  2. 新建Smoke。Coordinates设Explicit Map Channel；第一张用Channel1。
  3. 在Smoke中设Size0.3、Iterations5、Exponent1、Phase0。Coordinates的U/V/W Tiling为2 / 0.2 / 1。以上值来自原片05:00。
  4. 新建一张内部Composite：Layer1接条纹Gradient Ramp，Layer2接Smoke；Layer2的Blend Mode设Multiply，Opacity100。原片06:00可以核对Multiply。
  5. 将内部Composite接回外层Composite的Layer1。第二套条纹同样做一个内部Composite，再接外层Layer2；保留外层Layer2的Mask。
  6. 整个结果仍接Arnold材质Opacity。Smoke的暗处会降低条纹的不透明度，让条纹局部变淡或断开。

为什么是Multiply？在0–1的黑白值中，白色1乘条纹保持原值；黑色0乘条纹变成0；灰色让条纹变暗。由于结果连接Opacity，变暗意味着更透明。

本工程补充/推断设置：Smoke的W Angle45依据斜纹缩略图推断；第二张复制同样数值并使用Channel2，仍需进一步核对原片。沿用的灯光、相机、部分UV和渐变色标也尚未完全匹配。

底部烟雾后续：Falloff 与更柔和的边缘

这是06工程之后的步骤。已保存07工程，实际渲染后重新打开，核对四层连接和参数。仍是中间检查版，最终橙色和场景尚未完成。

  1. 打开 Map48 Gradient Ramp，把 Interpolation 从 Linear 改为 Ease In。Gradient Type 仍为 Linear。这两个下拉框控制不同的事情：前者控制黑白过渡速度，后者控制渐变方向形式。
  2. 打开 Composite49，把 Layer2 的 Opacity 从50改为80，Blend Mode 保持 Multiply。原片24:45可见。
  3. 创建 Falloff：Front 为白色、Side 为黑色；Falloff Type 选择 Perpendicular/Parallel，Direction 选择 Viewing Direction (Camera Z Axis)。Mix Curve 保留直线。
  4. 把 Falloff 接入 Composite49 的 Layer4，选择 Multiply、Opacity100。Composite仍连接材质Opacity。

为什么这样接：Falloff根据表面朝向镜头的角度输出黑白。白色保留已有烟雾，黑色使它透明，灰色部分保留。与原有纹理Multiply后，圆筒侧缘会减弱。它不会新增烟雾几何，也不是FumeFX体积烟雾。

Layer2的80是Composite混合强度，不等于整个物体80%不透明。提高这个值会让第二层Multiply对结果的影响更强。Ease In则改变渐变色标之间的过渡。

比较图：左/上为06，右/下为07。两张使用相同诊断镜头、尺寸和帧44；本次同时修改了三项，不能把全部差异归因于Falloff一项。

0–255值读自Gradient Ramp色标状态文字；颜色选择器Scene小数显示精度较低。例如右端选择器显示约1,0.701,0.089，色标状态显示255,179,23。因此本工程按整数读数复现，不声称恢复了原文件内部全部小数精度。

怎么理解：Composite的黑白信号一分为二。直接送入Opacity，决定哪里可见；送入Mapped Gradient，决定该处使用橙红、橙色还是浅黄。黑色区域虽然取到左端橙红，但Opacity同时为黑，所以不会显示成一整块橙色圆筒。

Scene与Display：请填写Scene值。截图里左端的Display是255,96,0，而Scene约为1,0.117,0；两者不是同一套数值。不要把Display的96直接填进Scene的绿色通道。

为什么橙色范围变大：把中间橙色色标移到93，会把橙色到右端黄色的过渡压缩在93–100的末端。Mapped输入必须接近白色，才会取到右侧黄色。

Gain在这里做什么：这两张Color Correction处理的是送进色谱的黑白纹理，并非直接调Emission。降低Gain会改变黑白信号，进而改变Mapped在色谱上取到的位置。透明度分支独立保留，所以不会直接把整条龙卷风透明度减半。

怎么操作：先看粒子，再看材质

  1. 打开03工程，回到 Frame 0，按 6 打开 Particle View，找到 Tornado_Dust_Event。按时间顺序播放到 Frame 30，避免只看最后一帧：Frame 100 时这组粒子已经全部消失。
  2. Birth：Emit Start = 0、Emit Stop = 60、Amount = 180。它决定何时产生粒子、总共生成多少；Amount 不是每一帧的数量。
  3. Position Object：选择 Vortex_Emitter_SUPPLEMENT。它是 Radius = 38 cm、Position = [0,0,80] 的 GeoSphere。发射模型不参与渲染，只负责产生位置。
  4. Speed：Speed = 8、Variation = 2、Divergence = 15。先给粒子初始运动；随后 Force 再改变运动。
  5. Shape Instance：选择 Vortex_Dust_Shape；模板 Sphere 的 Radius = 0.7 cm、Segments = 8；Scale = 100%、Variation = 30%。这是每颗粒子的可见模型。
  6. Material Static：使用 Vortex_Dust_Material_SUPPLEMENT。Arnold 材质 Base = 1、Base Color = RGB [205,150,70]、Specular = 0.1、Emission = 0.15，Emission Color 与 Base Color 相同。浅棕色负责尘粒颜色，少量 Emission 提高可见度。
  7. Force：加入 Tornado_Vortex_SUPPLEMENT，Influence = 1000。仅在场景创建 Vortex 不够，必须把它加入这个 Force 的列表。
  8. Delete：By Particle Age，Life Span = 40 frames、Variation = 0。粒子各自出生40帧后删除；最后一批在60帧出生，所以100帧归零。

如何确认它真的工作

重新加载同一工程，分别用 Force Influence = 0 和 1000 从头计算。Frame 30 两组都是90颗粒子，对应粒子的位置最大相差约70.74 cm，证明 Force 改变了运动。启用时 Frame 0 / 15 / 30 / 60 / 80 / 100 的数量依次为1 / 45 / 90 / 120 / 60 / 0。位置变化是功能验证，不等于教师效果一致性验收。

你可以另存练习副本，只改 Orbital Speed，再从 Frame 0 播放；观察绕轴变化。然后恢复0.5，只改 Radial Pull，再从头播放。一次只改一个值，更容易看出参数用途。

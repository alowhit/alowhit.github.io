Two Map Channels + Composite Mask

本节有三个实际渲染的可编辑工程。仍为材质学习阶段，尚不是最终龙卷风成片。先打开03_Normal_Masked.max，按M查看Slate Material Editor。

你在做什么？

Map Channel是模型上的贴图坐标编号。同一个模型可以保存两套UV，让两张条纹贴图各用自己的坐标。Composite把两张贴图合在一起，结果接Arnold材质的Opacity。

Map / ParameterValue作用与证据
Map22 / Map Channel1保留第一套条纹；沿用上一课
Map24 / Map Channel2使用第二套UV；原片07:00
Map24 / U Tiling, V Tiling, W Angle3.5, 1, 45°第二层条纹的重复次数与方向；原片07:00
Composite / Layer 1, Layer 2Map22, Map24两层Normal，Opacity均100；原片08:00
Layer 2 MaskMap26 Gradient Ramp控制第二层在哪些位置显示；原片10:00–11:00
Map26 / Gradient TypeLinear黑0 → 白50 → 黑100；11:00可见中点RGB255
Map26 / CoordinatesChannel1; U/V Tiling1; W Angle0不沿用条纹的45°旋转

在 Max 中按这个顺序检查

  1. 选择模型，检查第二套UV。此工程已直接写入Map Channel2；需在副本上加Unwrap UVW并选择Channel2才可在UV编辑器查看。
  2. 打开01版：只有Map24连接Opacity，看到的是第二套坐标上的条纹。
  3. 打开02版：Map22接Composite的Layer1，Map24接Layer2。Normal和100%且没有Mask时，第二层覆盖第一层；黑色像素不是“空层”。
  4. 打开03版：把Map26接到Layer2 (Mask)。白色显示第二层，黑色显示第一层，灰色按比例混合。
  5. Composite输出接材质Opacity。此时合成后的白色保留表面、黑色令表面透明。不要混淆Layer Mask与材质Opacity这两步。

还原范围：Channel2的UV移动依据原片04:00外观推断：将原U的左半移动+1，形成约0.5–1.5的范围。原片没有展示可确认的移动数值，不能称为逐值复制。第二套UV使用逐面UV顶点，尚未焊接。上一课条纹的部分色标也仍为估值。

检查相机、灯光与材质Base/Specular继承上一课补充值，所以渲染偏暗；老师最终场景、贴图动画及后续效果仍待制作。

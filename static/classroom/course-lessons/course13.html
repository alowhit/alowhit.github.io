Particle Flow basics · teacher checkpoints

已查看全片 84 张、约每 20 秒一张的画面，并对下列 12 个时点读取原分辨率截图。它覆盖操作顺序，但不是逐帧审阅。老师会来回试参数，下面按时间记录，不把不同试验的值拼成一个所谓最终版本。

Do it in this order

  1. Create → Geometry → Particle Systems → PF Source。在视口拖出发射器，并拖动时间滑块看粒子。
  2. 按 6 打开 Particle View。上面的 PF Source 接到 Event；Render 在 Source，Birth / Position / Speed / Rotation / Shape / Display 在 Event。
  3. 选择 Birth，比较 Amount 与 Rate。Amount 是这段时间总共生多少个；Rate 是按时间持续发射的速率。
  4. 创建 GeoSphere。把 Position Icon 换成 Position Object，Add 选择 GeoSphere001。它控制出生位置，不会自动把每颗粒子变成这个球。
  5. 选择 Speed，试 Direction、Reverse、Divergence。先看 Front 视图，确认粒子究竟往哪个方向走。
  6. Rotation 控制朝向；Shape 控制实际几何形状；Display 控制视口显示方式。把 Display 改成 Geometry 后才容易直接看出 Shape 的变化。
  7. 老师试过 Shape Instance 和 Teapot，但结尾回到 Shape 的 Torus 3D。要复制一个对象的形状，应在 Shape Instance 的 Particle Geometry Object 中明确选择对象。

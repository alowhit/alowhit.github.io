Understand it with three small changes

  1. For a separate practice copy, keep Auto Key OFF. Set Noise Amount = 0 and U Tiling = 1. Preview this map on the Plane to isolate the gradient.
  2. Set U Tiling = 13, with U Mirror ON: the gradient repeats and reverses direction between repeats, producing bands.
  3. Restore Noise Amount = 0.5, Size = 5, Phase = 0.25. Compare the texture with the clean bands. Change only one value at a time.

U Offset shifts the texture across the surface. Phase changes the noise pattern. Neither parameter moves the Plane itself. The screenshot shows Auto Key on and red animation markers, but does not establish the starting values or curve tangents.

Editable Arnold scene Material library

1. Plane + Arnold Standard Surface

Create a Plane: Length 400 cm, Width 400 cm, Length Segs 1, Width Segs 1, Z 5 cm; enable Generate Mapping Coords. Assign an Arnold Standard Surface: Base 0, Specular 0, Emission 0.5. This chapter draws the water pattern using Emission Color; a fine mesh is not needed for that color pattern.

2. Make the first bands

Add Gradient Ramp #25. Set Gradient Type = Linear, Interpolation = Linear, Explicit Map Channel 1. Black at 0, neutral gray at 50, white at 100. The exact middle RGB was not opened: the study uses 127.5/127.5/127.5 as a supplemental value.

The earlier demonstration uses U Tiling 20 and Noise Amount 1.0. These are intermediate values, not the later settings above. Your screenshot with U Offset 0.5 and Phase 0.25 shows a different state; it remains documented below and is not silently mixed into this static reconstruction.

U Tiling changes spacing. W Angle rotates the stripes on the Plane. Noise Amount changes the clean gradient pattern. Copy #25 to create #26 and #28, then change their Tiling and W Angle.

3. Combine the three directions

Add Composite #27. Connect #25 to Layer 1, #26 to Layer 2, #28 to Layer 3. Use Normal / Overlay / Overlay, all Layer Opacity 100%. The crossed patterns break the single-direction stripes into smaller shapes.

4. Add Smoke as the fourth layer

Add Smoke #29: Coordinates = Explicit Map Channel 1, Size 0.05, Iterations 5, Exponent 1.0, Phase 0, black/white colors. Connect it to Composite Layer 4. The last visible mode is Difference, at 100%.

The teacher first tries Object XYZ and much larger Size values, then switches to Explicit Map Channel and smaller sizes. Size 101.6 in Object XYZ and Size 0.05 in UV coordinates are different sampling setups; do not copy one number while keeping the other coordinate system.

5. Map the grayscale pattern to blue

Add Gradient Ramp #30, set Gradient Type = Mapped. Connect Composite #27 to its Source Map; connect #30 to the material's Emission Color. Interpolation stays Linear, Noise Amount 0.

Visible later flags: Position 34 → RGB (28,137,255); Position 53 → RGB (248,253,255). Right endpoint remains white. The left blue endpoint is not fully confirmed: this study uses RGB (0,12,255). These RGB values are the ramp's numeric values, not a sampled screenshot color.

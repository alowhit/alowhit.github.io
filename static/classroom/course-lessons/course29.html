用 Gradient Ramp 控制火焰形状的上下分布

本节原片为《录屏4》。已核对9个原分辨率参数时点；已补充对应MAX练习；本节参数截图来自老师原片，本机渲染另列在下方。

Cellular #1 ───────────────→ Composite #4 · Layer 1
Gradient Ramp #3 (W 90°) ─→ Composite #4 · Layer 2
Composite #4 → Gradient Ramp #2 · Source Map → Fire

两个 Gradient Ramp 的工作不同：#3 提供有方向的灰度渐变，与 Cellular 混合；#2 延续前节的黑白阈值处理。不要只按节点名字找参数，要看连线和节点编号。

  1. 保留上一节文件，另存新的阶段。
  2. 检查 Frame100 的 Cellular Offset：本片显示0/−200/−120。Frame0值尚需继续核对。
  3. 加入新的 Gradient Ramp 和 Composite，按上面的连线连接。
  4. Gradient Ramp #3 用 Linear，W Angle90°；中间灰色色标Position31、RGB128/128/128。
  5. Composite Layer1保留Normal；Layer2后续改为Soft Light；两层Opacity100。
  6. 检查原有Gradient Ramp #2仍接收Composite作为Source Map，然后分别渲染不同帧观察黑白边界。

为什么加入这层？Cellular负责不规则变化，线性渐变给不同高度提供不同的灰度条件，合成后再经过黑白阈值，轮廓会在不同高度形成不同的分布。这一段先制作黑白形状，尚未给出最终火焰颜色。

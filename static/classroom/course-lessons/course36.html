宽端加线与Soft Selection收口

以下接在04:00的Taper之后。保留Cylinder → Edit Poly → Taper，再添加第二个Edit Poly。新增三个学习工程，保留修改器层级；保存重开后检查到336 vertices、312 polygons。

1 · Connect：先给头部增加可弯曲的线圈

进入Edge，选中宽端最后一段的24条纵向边。点击Connect旁的小设置按钮：Segments=3、Pinch=0、Slide=0，确认。这会增加3圈环线，每圈24个顶点；后面收口才有足够的分段形成过渡。06:00原片可读到3/0/0，07:00显示新增环线共72条边。

2 · 只选开口最外侧一圈

清除Connect留下的72条边选择，再选宽端边界的24条边。不要把刚新增的3圈也一起选中，否则它们会一起缩小，头部容易变成细长瓶口。

3 · Soft Selection：让邻近线圈跟着少量收缩

ParameterSource value用途
Use Soft SelectionOn让未直接选中的邻近顶点也受到影响。
Falloff90.8 cm影响距离；离所选边越远，变化越小。
Pinch0.5调整影响曲线的形状。
Bubble0.0本例不增加额外鼓起的曲线变化。
Affect BackfacingOn背面的顶点也参与。
Edge DistanceOff本例不用沿边步数限定范围。

4 · Scale：收小截面，保留长尾长度

09:45画面底部显示X=100%、Y=30%、Z=30%。世界X是长尾方向，保持100%；缩小Y与Z得到较小开口。使用所选边圈的中心缩放。学习版对应这个已读出的操作值；后续拖动是否另有微调尚未逐帧确认，不能声称与片末每个顶点完全一致。

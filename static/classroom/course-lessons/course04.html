先认清这节课做到了哪里

片尾展示的是黑白断环与颗粒，尚不是你参考图里的蓝色发光水纹。先检查黑白图形，后续再接颜色与透明度。不要在这一步靠加亮Emission掩盖图案差异。

Slate Material Editor 接线顺序

  1. 建立Gradient Ramp #6，使用Radial，把黑白色标交替排列成多个圆环。所有色标的位置尚未核全，请不要把示例位置22或94复制给所有色标。
  2. 建立Swirl #7和Waves #9。三张图分别接Composite #8的Layer 1、Layer 2、Layer 3，模式见下表。注意接Layer，不是Layer (Mask)。
  3. Composite #8 → Gradient Ramp的Source Map，Gradient Type选Mapped。老师把这个节点命名为SpFL，利用黑白色标筛选输入的亮暗值。
  4. SpFL → Composite #12的Layer 1；Cellular #11 → Layer 2；Gradient Ramp #14 → Layer 3。Swirl #13是中途试验，片尾已经断开。
  5. 本片中途将Composite #12接到Arnold Standard Surface的base_color观察黑白纹理。最终蓝色、Emission、Opacity接线需要下一课继续核对，不能凭这张片尾图补称老师数值。

每个参数到底在改什么

Radial让渐变按离中心的距离变化，所以黑白色标形成圈。Mapped / Source Map把输入图的亮度当作查色依据；改色标位置会改变哪些弧段保留下来。Multiply让黑色区域压暗底图。Cellular Size控制纹理尺度，Spread控制细胞颜色覆盖范围。Swirl Twist改变旋涡图案；这里没有证据表明它在扭曲模型。

先看四个阶段，再打开节点

1 · Radial：先画圆环

Gradient Ramp的黑白色标按半径形成明暗圈。这里共有17个不同位置，额外3个模板色标与100重合，不多产生圆环。

2 · Multiply：让圆环出现缺口

把圆环、Swirl与Waves相乘。Swirl和Waves里的黑色会压暗圆环的一部分，形成断开趋势。

3 · Mapped：把灰色筛成清晰弧段

SpFL读取Composite #8的亮度。黑色色标21为补设；白色色标24来自20:00原片，Interpolation为Ease In。

4 · Cellular：加上细小颗粒

Cellular接第二层Multiply，另一个Radial接第三层Darken 90%。颗粒只改变纹理，不会增加模型面数。

打开工程后怎么学

  1. 打开MAX，按M，选择“Course04 source structure PARTIAL”视图。若只看到局部节点，使用Zoom Extents显示全部节点。
  2. 双击06_Radial_Rings_PARTIAL_FLAGS，检查Gradient Type = Radial。移动一个白色色标会移动对应亮圈；把它改黑则会压掉这段亮圈。
  3. 双击07_Swirl_SOURCE_24m，检查Twist = 10，Center Position X/Y = −0.5。先把Twist临时改为5，渲染比较弧段变化，再恢复10。
  4. 双击10_SpFL_EaseIn_PARTIAL_FLAGS，检查Gradient Type = Mapped、Source Map来自08_Multiply_Rings_Swirl_Waves。把白色色标24临时改为35，观察保留下来的亮部如何改变，再恢复24。
  5. 双击12_Final_Darken90，第二层是Cellular，第三层是Radial。临时把第二层Opacity降到0，对比颗粒消失后的纹理，再恢复100。
  6. 四阶段材质也保存在材质库中，名称以01、02、03、04开头；选中Wave_Plane后可逐个赋予材质再渲染。

哪些值来自原片，哪些仍是补设

Swirl Twist 10、Contrast 1、Center −0.5，Cellular Size 0.01、Spread 0.35、Iterations 5，以及Composite的混合模式来自已核对时刻。Waves采用08:40的Max 30、Min 60、Radius 2、Sets 3，尚未确认后续是否再次修改。

圆环色标序列与#14色标还未逐个核全；SpFL黑色21、Cellular灰色RGB128、Plane 200×200 cm、相机位置(0,−320,190)、FOV45为补设。渲染使用Arnold Standard Surface的Base 0、Specular 0、Emission 1检查纹理，因此与老师的受光亮度不能直接比较。后续仍需匹配原场景灯光、相机、完整色标、蓝色与Opacity及动画。

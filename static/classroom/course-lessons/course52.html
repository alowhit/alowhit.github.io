Sphere · Opacity Noise and UV inspection

源片：课堂教学视频3.mp4，16:17。本轮检查34张约30秒间隔画面，并放大01:30、02:30、03:00、15:30参数。以下是有证据的操作阶段，不宣称逐帧、逐值全部一致。

01 · Start from the previous sphere

保留 Ball：Radius40cm、Segments64、Generate Mapping Coords开启，位置(0,65.956,40)。材质仍为 Arnold Standard Surface：Base0、Specular0、Emission1、Emission Color场景线性RGB0.104，Gradient Ramp连接Opacity。球不是通过Noise修改器变形：本课Noise位于贴图内部，改变的是透明度图案。

02 · Adjust the Gradient Ramp

双击Gradient Ramp，在Coordinates设置Explicit Map Channel、Map Channel1、U/V Offset0、U/V Tiling1、W Angle90°。Gradient Type与Interpolation均为Linear。黑色区域透明，白色区域可见，灰色介于两者之间。01:30选中色标Position37、RGB41；随后色标继续移动，03:00和15:30显示Position55、RGB56。不要把不同时间点的值当作同一最终状态。

打开01工程渲染，再打开02渲染。两份仅改变Noise Amount，因此可以直接观察：整齐的带状边缘变成有缺口的边缘。当前学习版背景比老师深，镜头、曝光和部分渐变位置仍未精确匹配。

04 · Inspect the UVs

  1. 选中Ball，在Modify面板添加Unwrap UVW。
  2. 点击Open UV Editor。球体已有生成的贴图坐标；老师展示的是矩形网格。
  3. 观察UV Editor里的网格与视口球体上的接缝；源片约07:00选边、07:30选面，随后调整显示与缩放。
  4. 03工程保留Unwrap UVW，供你打开编辑器检查。未凭抽帧猜测并修改UV顶点的位置。
  5. 11:00之后老师的堆栈仅剩Sphere；因此02工程是无Unwrap修改器的材质阶段，03是中间检查档，不应误当最终堆栈。

UV可以理解成“球表面各点去贴图哪里取颜色”。本课图案沿球体上下分布，由已有UV与W Angle90°共同决定。打开编辑器查看UV，本身不会自动改变材质。

How to build the keys manually

  1. 先另存学习副本，在Frame0输入起始值。
  2. 开启Auto Key，移动到Frame100，再输入终点值。
  3. 关闭Auto Key，拖动时间轴观察。U/V Offset移动透明度图案，Phase改变噪波形态，Ball Rotation旋转模型。
  4. 如果只想比较贴图动画，可在单独副本中保持球体旋转不变；不要同时改变多个参数后猜测是哪一个产生效果。

Render Setup and AVI

  1. 按F10 → Common → Time Output → Range，输入0和100。原片17:20已确认Range被选中，Every Nth Frame为1。
  2. Output Size：Width640、Height480、Pixel Aspect1。
  3. Render Output → Files，选择AVI；在AVI File Compression Setup中选择Uncompressed。原片21:00显示该选择。
  4. 保存路径后渲染。当前交付的AVI由101张真实Arnold渲染帧合成，使用未压缩BGR24；没有声轨。它不是录制视口。

仍需核对全部关键帧、插值、球体旋转、渐变色标、镜头及曝光。背景比源片深的差异仍保留在待办中。

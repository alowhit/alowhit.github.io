先分清三个参数

  • Scale：改变球有多宽、多高；Z Scale为0时球被压平。
  • Z Position：改变球中心所在高度；它与Z Scale是两条不同的动画轨道。
  • Opacity：改变哪里可见。Falloff与Gradient Ramp组合后，轮廓和图案共同控制透明度。

Curve Editor · 同样的起止值，不同的变化速度

这是第3份切线学习工程，已保存后重新打开并读取关键帧。它用于比较后段动作，不是整段精确复刻。前两份工程保留原来的设置。

按轨道分别设置

  1. 选中Ball，打开Curve Editor，展开Transform → Scale。起点Time 0为X/Y 50%、Z 0%；终点Time 100为X/Y 150%、Z 120%。
  2. 在Time 0的关键帧属性中，将Out设为Fast；Time 100的In设为Slow。本学习版由原片图标与曲线形状推定这些预设。观察球先快速长大，接近终点时变化逐渐减小。
  3. 切换到Position → Z Position。关键帧为Time 0: 0 cm、Time 50: 0 cm、Time 100: 38 cm。Time 50的Out设为Slow，观察后半段从缓慢上升逐渐加快。
  4. 拖动时间轴时同时观察底部Z读数和Scale读数。Scale改变尺寸，Position改变中心高度；两条轨道要分别检查。

In控制接近关键帧的速度，Out控制离开关键帧的速度。Slow Out表示离开该关键帧时较慢；Fast Out表示离开时较快。见Autodesk Tangent Types。

分开理解三种变化

  1. Scale：球由扁平变高、变宽，起止值仍为50/50/0% → 150/150/120%。
  2. Z Position：前50帧中心高度保持0，之后加速上升至38 cm。
  3. Gradient Ramp → Coordinates / Noise：U Offset从0到1、V Offset从0到−0.5、Phase从0到4。前两项移动图案，Phase改变噪波形态。

参数来源：纹理终点来自第53课已核对的画面；起点0以及将这一动画延续到第55课属于推定，尚未恢复本课老师的完整纹理轨道。纹理使用默认Bezier插值。S曲线控制柄仍为按画面估计。此版本保留模型现有旋转，没有加入第53课尚未证实的旋转轨迹。

在Max里检查与输出

  1. 打开第6版，关闭Auto Key，依次拖到Frame 0、25、50、75、100。Frame 0的Z Scale为0，模型会被压平，这是学习版采用的原片起点。
  2. 分别查看Ball的Scale与Z Position轨道，再打开Gradient Ramp查看U/V Offset与Phase的变化。不要把贴图移动误认为模型移动。
  3. Render Setup → Common → Time Output → Range设为0–100，Every Nth Frame为1。当前输出640×480、30fps；帧率沿用学习工程，未确认为老师设置。
  4. 当前AVI由真实渲染序列合成，格式为未压缩BGR24，无声轨；并非视口录像。

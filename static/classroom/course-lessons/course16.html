From spheres to a cloud · material study

已查看 75 张间隔画面，并记录 17 个原分辨率参数时点。本节已有源文件学习工程及完整动画；逐值材质与视频末段一致性仍待补齐。

先理解这两条线

Falloff #0 + Cellular #1 → Composite #2 → Opacity
Blue Falloff #3 → Self-Illumination

Opacity 这条线让球的边缘和内部部分区域变透明；颜色那条线控制云团的颜色。底下仍然是很多球形粒子，并非这张图就证明使用了体积模拟。

本节原片使用 Scanline + Standard (Legacy)。上一节的粉色 Arnold 球团只是运动检查材质，不是老师这节的云材质复刻。当前 Test7 源文件的保存状态也要与视频时点分别核对。

颜色数值怎么照着输入

  1. 打开蓝色 Falloff #3，点击 Color 1 色块。在颜色选择器中确认使用 Display 一侧的0–255 RGB，输入164、239、255，或输入 Hex A4EFFF。
  2. Color 2 要按视频阶段填写：17:25为00A2FF，19:15为004EFF，19:50为0037B3。它们是前后修改，不是三张需要叠加的贴图。
  3. Scene Linear 一栏使用0–1附近的数值；截图中这栏只有约三位小数，不能当完整精度的原生保存值。不要把164直接填进Scene Linear。
  4. Color 1 与 Color 2 是 Falloff 的两个颜色端点；Towards/Away + Object + Point001 决定哪些表面偏向哪一端。移动Point001会改变颜色分布，而不是移动真实灯光。

源工程 Color 1 原生读数[96.5624,221.12,255]与视频显示RGB[164,239,255]属于不同表示方式。它们数值不同不等于颜色一定不同；当前保留源工程原生值，不用截图四舍五入值覆盖。

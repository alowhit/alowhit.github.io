1 · Sphere

Create → Geometry → Standard Primitives → Sphere。设置 Radius 40 cm、Segments 64、Smooth On、Hemisphere 0、Generate Mapping Coords On。04:00显示位置 X0 / Y0 / Z40，即球心抬高40 cm，底部接触地面。01_Sphere保留这个位置。

2 · Arnold Standard Surface

命名 Ball，设置 Base 0、Specular 0、Emission 1、Emission Color white，赋给球体。这一阶段看到的是发光的白圆：没有靠基础反射产生的球面明暗，这是老师的中途状态。灰色视口里的立体阴影不等于最终Arnold渲染。

3 · Physical Camera

老师约10分钟创建 Physical Camera，随后移动球体和相机。19:00球体位置可读为 (0,65.956,40)，02和03工程采用这一后期位置。精确相机数字尚未确认，学习工程使用补齐设置：Camera(0,−125,40)，Target(0,65.956,40)，FOV45°，Film Width36mm，DOF与Motion Blur关闭，Exposure保持运行时默认。相机位于房间内部，避免从外部穿墙拍摄。

4 · Gradient Ramp → Opacity

在Slate创建 Gradient Ramp，将输出连接到 Ball 的 Opacity。白色保留表面，黑色使表面透明，灰色处于两者之间。这不会删除球体的网格。设 Gradient Type Linear、Interpolation Linear、Explicit Map Channel1、U/V Tiling1、U/V Offset0、W Angle90°、Noise Amount0。

19:00选中的黑色Flag Position为 57。学习版使用0黑、57黑、72白、100白；其中72是按画面位置估计，不能标成逐值确认。额外模板Flag重叠在100，不改变这段渐变。将W Angle从0改到90会旋转遮罩方向；移动黑白Flag改变透明区域和过渡宽度。

在 Slate 里怎样改

  1. 双击接到 Ball → Opacity 的 Gradient Ramp，展开 Gradient Ramp Parameters。
  2. 在色带下面选择内部白色色标，读取 Position。现有学习版为44，将它改为43。

Exposure Control · 为什么同一材质会偏暗

已实际完成一次单变量对照：使用第07阶段相同的球体、Opacity、Emission Color、房间和相机，只添加场景曝光控制。两份图都实际渲染，08工程已保存并重新打开。这是验证有效的学习修正，尚不是老师曝光参数的逐值证明。

原来背景为中灰、条带较暗；启用后背景接近白色，条带亮度也更接近原片22:30。这个结果说明不能只核对shader数值，还要核对场景曝光。它没有证明相机位置、色彩管理和老师所有设置已完全一致。

在 3ds Max 里怎么设置

  1. 先打开07工程并另存副本。按8打开Environment and Effects。
  2. 在Exposure Control下拉框选择Physical Camera Exposure Control，勾选Active。
  3. 选择Use Per-Camera Exposure，设EV Compensation = 0。本例Physical Camera自身的Exposure Value保持6。
  4. 保持表中控制器设置，再从同一相机渲染。不要同时调Emission、灯光或渐变，才能看出曝光的作用。

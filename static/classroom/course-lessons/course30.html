先分清三个操作：Cellular的Size控制斑块大小；Coordinates Tiling改变斑块比例；Gradient Ramp的Solid插值把灰度切成黑白。之后加入另一张渐变，控制不同高度的亮度或形状分布。

操作步骤

1. 平面与细胞贴图

建立平面，开始查看Cellular；本课基于二维贴图制造火焰形状。

2. 细胞参数实验

观察Size、Spread、Fractal及阈值对细胞轮廓的影响。

3. 拉伸和分形

Cellular设置为圆形、分形，调整阈值以得到分叉轮廓。

4. 竖向渐变

Gradient Ramp旋转W90°，将灰度变化改成高度方向；中间旗标和插值改变火焰高度分布。

5. 贴图偏移动画

第100帧Cellular坐标偏移可读为(0,-150,50)，模型不必实际向上移动也能让图案流动。

6. 噪声边缘

Gradient Ramp的噪声对高度遮罩形成不规则边缘。

7. 调整动画中的纹理

查看第71帧，Gradient Ramp的噪声相位3.55；与终点相位5的样本一致，但完整控制器未核验。

蓝色水波纹：Color 和 Opacity 分开接

本节核对原片8个时间点。它解释老师的接线过程，但还不是逐帧核对完成，完整复刻尚未验收；下方已提供颜色与透明度阶段工程。上一课的黑白节点练习不能代替这里的完整颜色分支。

先照着接这三步

  1. Composite #5 → Gradient Ramp #19 的 Source Map。#19 使用 Mapped，把输入图的明暗重新分配为蓝色。
  2. Composite #12 → Gradient Ramp #18 的 Source Map。#19 → Composite #20 的 Layer 1；#18 → Layer 2。Composite #20 → Arnold Standard Surface 的 emission_color。
  3. 另建 Gradient Ramp #21，使用 Radial，中心白、外圈黑，接 Arnold Standard Surface 的 opacity。它用来隐藏平面外围，不是把蓝色变暗。

Emission Weight控制发光贡献；emission_color接颜色图；opacity决定哪些表面可见。截图没有证明这里使用了几何位移或水流模拟，请先把这些贴图接对，再比较效果。

打开后怎么练习

  1. 打开MAX，按M打开Slate Material Editor，选择“Course05 Color and Opacity PARTIAL”视图。节点没显示全时，使用视图的Zoom Extents。
  2. 选择平面上的Arnold材质。Emission Weight是0.5，emission_color接Composite #20，opacity接Gradient Ramp #21。
  3. 先暂时断开opacity并渲染，比较方形边缘；重新接回后再次渲染，观察外围消失。练习时另存文件。
  4. 选中#18，中间色标Position 33、RGB 30/73/165来自片尾。其他尚未核齐的颜色以参数文件中的supplements为准。

这里验证的是颜色合成与透明度接线。前置纹理和场景未核齐，所以还不能据此判定考核作业完成。

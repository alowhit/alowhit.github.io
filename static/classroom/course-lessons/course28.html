让 Cellular 形状动起来：Z Offset animation

已核对8个原分辨率时点。这里操作的是 Cellular 的 Object XYZ Coordinates，不是水纹 Gradient Ramp 的 Noise Phase。

  1. 打开上一节 Cellular → Gradient Ramp → Fire 材质，双击 Cellular。
  2. 在 Frame 0 检查 Coordinates：Offset X/Y/Z = 0/0/0；Tiling X/Y/Z = 1/0.3/1。
  3. 开启 Auto Key，移动时间滑块到 Frame 100。
  4. 把 Z Offset 改为 −20。X Offset 和 Y Offset 保持 0。
  5. 关闭 Auto Key，再来回拖动时间滑块，检查 Z Offset 是否随时间变化。预览贴图或重新渲染不同帧；旧的 RenderView 图片不会证明动画已经更新。
  6. Render Setup → Common：Range 0–100，Every Nth Frame 1，Width 640，Height 480。
  7. Render Output → Files：原片保存 TextureTest.avi，然后渲染序列。

这个参数做什么？平面本身不必移动；Z Offset 改变程序贴图取样的位置，因此平面上的黑白图案随时间变化。Y Tiling = 0.3 继续负责拉长斑块。动画曲线的切线没有在这些画面中展示，不能声称它是匀速线性运动。

补充操作：若 AVI 编码器不可用，可以先输出 PNG sequence，再合成 MP4。这是补充交付方案，不能写成老师在原片使用了 MP4。

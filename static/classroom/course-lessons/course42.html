Two Sided：同一个火球，正反面不同颜色

本轮审阅覆盖全片 39 张分钟间隔图，并提取、检查关键参数画面；并非逐帧审阅完成。原生 Class2 节点与视频的 Two Sided 接法一致，下面把课堂中途值与保存版本分开。下载可编辑学习工程

1 · 00:00–03:10：从一个材质变成正反面两个材质

  1. 按 M 打开 Slate Material Editor，读取 Cylinder001 的材质。
  2. 在 Materials → Arnold → Surface 下添加 Two Sided。这是 Arnold 的材质节点。
  3. 把原有红黄 Standard Surface / Material #45 接到 front。
  4. 创建第二份 Standard Surface / Material #49，接到 back。
  5. 把 Two Sided 赋给 Cylinder001。两份 Standard Surface 使用同一个 Composite #3 → Opacity。
Noise #1 → Gradient Ramp #5 → #45 Emission Color → Two Sided / front
Noise #1 → Gradient Ramp #6 → #49 Emission Color → Two Sided / back
Composite #3 ─────────────────→ 两个材质的 Opacity

怎样理解：front / back 指网格表面的正反面，不是画面的左边和右边。透明的部分能露出后面的表面，所以同一张画面会同时看到两套颜色。这里只改变颜色分配，不会自动增加模型厚度。

2 · 约03:10–06:30：把 back 改为蓝紫色

第二份材质使用 Gradient Ramp #6，Gradient Type = Mapped，Source Map = Noise #1，Interpolation = Linear，Noise Amount = 0。05:30 正在修改一个 Position 25 的色标，选择器中场景浮点值与显示 RGB 是两组数，不能直接混用。原生 Class2 保存后的位置又有变化，因此不把05:30当作最终配色。

Class2 中 #6 的色标位置为 0、16.835018、72.727272、90.235695、100；颜色与原生色彩数据已经保存在下载工程中。两份材质均 Base = 0、Specular = 0、Emission = 1（详见读回文件）。先用原生节点比较，不必凭截图吸色重建。

3 · 约08:30–11:40：修改模型和添加第二个 Noise

教师返回 Edit Poly 检查头部，再在原 Noise 上方加 MeshSmooth，随后加新的 Noise。课堂 10:30 与 11:30 显示 MeshSmooth 的 Iterations = 1、Smoothness = 1；原生 Class2 保存值为 Iterations = 2，学习工程保留保存版，并不冒充本时点。

视频时点顶部 Noise 的可见设置制作意义
10:50Scale 100；Fractal On；Roughness 0；Iterations 6；Strength (50,50,0)试较强的局部变形
11:00Strength (20,30,0)中途调小 X 方向
11:10Strength (30,30,0)；Animate Noise On；Frequency 0.25启用随时间变化的模型噪波
11:20Strength (30,30,0)；Frequency 1.0继续试动画频率；播放中 Phase 与时间滑块可能刷新不同步
Class2 保存版Strength (30,30,0)；Frequency 0.8；MeshSmooth Iterations 2已有原生工程的另一个状态，不倒推成所有视频时点

这里的 Noise modifier 改模型轮廓；Slate 里的 Noise map #1 改表面图案。两者名称相近，但改的是不同东西。

4 · 约12:30–36:50：渲染、检查，再改 Noise map 动画

12:30 的 Render Setup 显示 Arnold、200×100 输出和 0–100 时间范围；随后 RenderView 可见 400×200。中间大段时间是在渲染和播放检查，不是不断添加新节点。不要把 Render Progress 的当前帧号当成后方参数面板的时间。

36:55 的 Noise #1 在 Frame 100 明确显示：Coordinates = Explicit Map Channel 1；Offset = (0.025, −2, 0)；Tiling = (1,0.5,0.5)；Noise Type = Turbulence；Size = 0.1；Low / High = 0.05 / 0.4；Levels = 3；Phase = 1.5。这与 Class2 保存版吻合，解决了与上一课 Phase 2、Offset (2,−6,0) 的阶段差异。

5 · 约37:00–38:51：开始创建 Sphere001

教师创建球体并移到火球头部。38:20 的位置栏显示 (0,0,150)。此处只是开始做核心，本章截图尚不足以确认球体最终材质、全部尺寸及外层 Cylinder002 的制作；这些应继续核对下一课，不能提前把后续效果写成已完成。

这些参数各做什么

Parameter用途
Opacity输出透明度分布；这张黑白图片本身不等于带透明背景的成品渲染。
UV Channel指定按哪套UV布局把表面采样到图片。
Image Size图片像素尺寸。DiffuseMap早期256；Opacity中途2048，末尾512。
Padding向UV边缘外扩展像素，减少接缝处漏色。
Files Only输出文件；不能仅凭这一项认为材质已经自动换成烘焙图片。

接线怎么理解

两张 Cellular 和一张 Noise → Composite → Standard (Legacy) 的 Diffuse Map 与 Opacity Map。同一张灰度图控制表面颜色和透明程度。本版已按原片11:05改为Normal100 / Hard Mix100 / Multiply20。与旧02版相比，输出形成更清晰的硬边碎片。输入Cellular和Noise仍是补充值，因此不代表老师最终图案。

参数与用途

  • 两个Plane均为120×120 cm、Length/Width Segs 1、Generate Mapping Coords开启；Plane001位于[0,0,0]，R位于[0,0,18.174] cm。Plane001原材质未知，当前未赋材质。
  • 补充值：Cellular Size 9 / 4、Spread 0.7 / 0.5、Noise Size 12，决定纹理的尺度与细节；这三张输入图的生成值仍为补充；Composite已用原片确认的Normal100 / Hard Mix100 / Multiply20。
  • Coordinates：Object XYZ，XYZ Tiling 1。先前 UV 诊断设置已恢复。
  • Bake To Texture：Opacity、Self、UV Channel 1、512×512、Padding 2、JPG、Files Only。UV Channel 决定把模型表面展开到哪里，Padding 在UV边界补像素以减少接缝，Files Only 只输出文件。

为什么先前输出全黑

本机安装的 Scanline Opacity 脚本查询 opacity_map，而 Standard (Legacy) 提供 opacityMap，导致没有取到输入图。这由实际接口读回和修正前后输出确认；不是灯光不够。

这一课在改什么？

Scale 控制物体大小。X/Y/Z为三个方向；100%代表原始大小。老师的球在Frame100的Z Scale是91.505%，因此竖向稍扁。把同一个关键帧的Z改为100%，恢复原始高度。这里不需要改Shader、Radius或删除关键帧。

Follow in Max · 自己操作

  1. 打开 01_Before_Z91_505.max，选中 Ball。拖动时间轴0→100，观察球体高度变化。
  2. 打开 Graph Editors → Track View - Curve Editor。
  3. 在左侧展开 Objects → Ball → Transform → Scale，选中Scale。横轴是Frame，纵轴是Scale百分比。
  4. 找到Frame100的末尾关键点，右键打开关键帧属性。先确认 Time = 100，再修改 Z Value = 100；X和Y保持100。
  5. 关闭关键帧属性，比较修改前后曲线：末尾Z值回到100。保留两个关键帧，本练习只修正数值。
  6. 拖动0、50、100帧比较高度，另存新文件。可打开 02_After_Z100.max 对照。

不要混淆两种“时间”：03:44是教学视频播放位置；Time100是被编辑关键帧的帧号。老师03:44的主时间轴停在93，但属性窗口编辑的是Time100的关键帧。

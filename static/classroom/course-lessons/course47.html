  3. 双击Falloff，Falloff Type选Distance Blend，Falloff Direction选Object。在Object按钮中拾取Point001。

3 · 这些参数到底在控制什么？

Object / Point001指定计算距离的参照位置。它是Helper，不是新灯光。Near / Far Distance指定距离混合的区间；Mix Curve改变区间内部的混合速度。因此移动Point、修改Far、拖曲线会改变不同的东西，练习时每次只动一个。

目前两个学习档保留前课Luminance5 cd/m²、同一补充Camera和灯光，所以可以比较Far的变化；不能用它们证明已经匹配老师画面的亮度或构图。老师本课多个RenderView仍在渲染或显示Render Aborted，不作为无噪点成片。

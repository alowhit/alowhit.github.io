1 · 00:00–05:30：先把 Noise 放到球上

  1. 延续上一课的 Sphere001，位置约 (0,0,150) cm。课堂 Radius = 58 cm，Segments = 32，Generate Mapping Coords 开启。

  1. 加入 Falloff #20：Perpendicular / Parallel，Viewing Direction (Camera Z-Axis)，Front 白、Side 黑。

  3. Noise #19 接 Composite #21 的 Layer 1；Falloff #20 接 Layer 2。原生保存值为 Normal / Darken，两个 Opacity 都是100。
  4. Composite #21 接材质 Cutout。此阶段用灰度变化得到柔和边缘。

3 · 约10:00–15:30：颜色与硬边分两路制作

Noise #22 → Gradient Ramp #23 (Mapped) → Physical Material / Emission Color
Noise #19 + Falloff #20 → Composite #21 → Gradient Ramp #24 (Mapped) → Cutout

火球为什么会动：Phase 与 Offset 的实际读值

下面是 Class2 保存工程的六个时刻读值，不是从截图猜出的数值。它们是“这一帧计算出的参数”，不能据此断言每个时刻都有 Key。表格取小数便于输入，原始浮点数见证据文件。

先分清三个位置

  • Object / Position：移动整个模型。
  • Map / Coordinates / Offset：移动贴图采样位置，模型可以留在原地。
  • Noise / Phase：改变 Noise 图案本身。不要把 Noise 的 Phase 和 Coordinates 内其他 Noise 控件混在一起。

在本工程里，Gradient Ramp #9 / #12 的 Phase 始终为0，但 U Offset 随时间改变。因此仅看 Phase 不动，不能判断贴图没有动画。Noise #1 / #7 则同时改变 Phase 与 Coordinates Offset。

  3. 将 Time Slider 设为0，查看 Noise / Phase = 0 和 Coordinates / Offset = (0,0,0)。
  4. 把 Time Slider 设为100，查看 Phase = 6、Offset = (7,−10,0)。保持 Auto Key 关闭，只观察参数，不要覆盖现有动画。

Generate Mapping Coords 给模型生成 UV；Unwrap UVW → Open UV Editor 用于检查或编辑这些 UV；贴图里的 Coordinates → Tiling / Offset 则改变贴图取样位置。三者不能互相替代。

三个效果模型有 UV；Loft001 没有 Map Channel 1。背景是否需要 UV 取决于其材质是否使用 UV 贴图，不能仅因通道不存在就认定渲染错误。UV seam edges 是相邻几何面在 UV 中断开的边数，圆柱展开通常需要接缝；这个数量本身不是错误数。范围中的约 0.0000001 偏差是浮点精度量级。

你在 Max 里怎么查看

  1. 先用 Save As 保存检查副本，选中 Cylinder002。
  2. 添加 Unwrap UVW，设 Map Channel = 1，打开 Open UV Editor。
  3. 先看现有展开，不要立即按 Flatten Mapping；重新展开会改变当前火焰贴图分布。
  4. 比较 Cylinder001、Cylinder002 和 Sphere001 的布局，再回到材质的 Coordinates 检查 Tiling / Offset。

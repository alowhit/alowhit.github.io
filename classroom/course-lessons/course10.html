Follow in 3ds Max

  1. Create → Geometry → Standard Primitives → Cylinder，先输入尺寸和分段。
  2. Convert To Editable Poly，进入Polygon选择顶盖、底盖并删除。仅删除两端，不要删侧面。
  3. 在保留UV的侧面模型上依次加入Stretch、Noise、Taper。列表最上方显示Taper，实际从下往上计算。
  4. 逐个切换修改器的显示开关：Stretch决定腰部，Noise打破对称，Taper把顶部展开。
  5. 拖动时间轴检查Noise变化。本练习已比较0、50、98、100帧的真实顶点数据，形状确实随时间改变。

检查用的紫色Arnold材质、相机、灯光和背景是补充设置。当前沿用圆柱原生UV，不冒充老师完成了Unwrap UVW；老师的场景背景与最终材质仍待接入。

补习：UV 编辑发生在形变之前

本次追加查看08:00–10:25每5秒一张，共30张原片截图；不是逐帧完成复刻。下面6个时点解释老师的操作顺序。

先区分三个动作

  • 编辑UV点：改变图片落在模型表面的对应位置。它可以让纹理拉伸、压缩或出现接缝，而模型轮廓不一定变化。
  • 缩放/平移UV编辑器视图：只是把屏幕上的布局看大、看小或移到中间，不等于改变UV数值。
  • Stretch / Noise / Taper：后续作用于模型形状。不要用这些修改器代替UV修正。

按这个顺序理解老师的步骤

  1. 开口圆柱准备好后，加入Unwrap UVW，打开Open UV Editor。观察侧面是否成为一片连续的矩形网格。
  2. 进入Vertex层级，检查接缝边界和局部UV点。原片08:00有临时折线，09:25显示完整规则矩形；精确移动过程尚未逐帧核对，先不要照着中途折线制造最终缺口。
  3. 查看完整UV布局。圆柱周向绕一圈对应矩形水平方向，高度对应垂直方向；棋盘格可帮助观察纹理是否被拉伸。这里是概念说明，具体UV方向仍以工程中的实际映射为准。
  4. 保留带Unwrap的另存版本后，再Convert To Editable Poly。原片10:05确认堆栈已只剩Editable Poly。
  5. 接着再做本页已有的Stretch、Noise、Taper阶段，比较纹理随形状变化的表现。

目前工程的限制：已交付模型沿用圆柱原生UV；本次新增的是原片步骤核对，没有修改MAX，不能把网页解释当成手工UV步骤已经完成。

08:00 · UV vertex editing

Unwrap UVW 位于 Editable Poly 上方。UV编辑器处于Vertex层级，左侧边界有折线形变，部分UV点正在选择中；右侧圆柱仍保持圆柱外形。这里只能确认编辑过程，不能把这个中途折线当最终UV。

09:00 · Inspect a UV corner

UV编辑器仍放大显示局部边界，底栏显示U/V/W为0/0/0。读数对应当前选择状态，并不是给全部UV输入0；否则贴图会挤成一个点。此图不足以恢复所有顶点的坐标。

09:25 · Inspect the complete island

缩放到可见完整侧面UV，呈规则矩形网格，外边界绿色。它是圆柱侧面展开后的纹理坐标布局。此图没有显示全岛精确边界数值，因此只能确认矩形形状，不能声称每个UV点逐值复原。

09:35 · Return to the modifier stack

关闭UV窗口后，修改器列表仍有Unwrap UVW和Editable Poly，正浏览Modifiers菜单。菜单出现不表示已添加某个修改器。

10:00 · Convert To Editable Poly

右键菜单展开Convert To，指向Convert to Editable Poly。此操作用于把当前结果收进可编辑模型；跟做时先另存一份保留Unwrap堆栈的工程，方便回改。

10:05 · Conversion result

右侧堆栈只剩Editable Poly，证明上一步转换已发生。画面中模型仍为开口圆柱，后续才添加形变修改器。

仍待完成：更细的UV点编辑和精确坐标核对、应用到独立MAX、检查接缝与后续纹理动画的一致性。没有证据确认的焊接、自动展开或归一化命令，不写成老师已执行的步骤。

Phase关键帧核对结论

播放器运行时，截图里的Phase和时间滑块读数不总相等。例如12:35面板Phase11、滑块21；12:40面板Phase86、滑块76。可能存在界面刷新不同步，不能据此反推出老师设置了偏移或复杂曲线。当前未看到关键帧属性或Curve Editor，精确端点和切线仍未证实。

Autodesk说明：Noise的Phase默认会在活动帧范围两端建立关键帧，Frequency调节运动速度，Animate Noise控制该动画的播放。Noise Modifier官方说明。这解释软件机制，不能替代老师工程的具体关键帧证据。

现在怎么跟做

  1. 在Stretch上方加Noise，Seed0、Scale20、Fractal Off、Strength X2/Y2/Z0。
  2. 开启Animate Noise，Frequency0.25，播放观察模型轮廓；先不修改材质的Noise节点。
  3. 如果要比较某一帧，先停止播放，再查看Phase和时间滑块；需要逐值复制动画时打开Track View查看真实关键帧。
  4. 现有工程把Phase设为Frame0=0、Frame100=100，并使用Linear切线。该项仍是演示补充，尚未证明与老师相同。

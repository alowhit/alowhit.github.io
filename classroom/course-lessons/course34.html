1 · Keep two separate branches

Composite #9 → Gradient Ramp #10 → Physical Material / Emission Color：决定火焰颜色。
Composite #3 → Color Correction #27 → Physical Material / Cutout (Opacity)：决定平面哪些位置留下、哪些位置透出背景。900秒画面清楚显示第二条线来自#3，而不是#9。

打开 Slate Material Editor，找到#3的输出，拖到新增Color Correction的Map输入，再接到Physical Material的Cutout (Opacity)。保持原有Emission Color线。黑色遮罩部分透明，白色部分保留，灰色部分部分透明；把颜色设黑本身不会自动挖掉平面。

2 · Color Correction #27

Lightness选择Advanced，模式Gain。按后期943.54秒画面填写：

ParameterValue用途
Gain RGB200调整遮罩亮度
Gamma / Contrast RGB3改变灰阶分布，影响火焰边缘的保留程度
Pivot RGB1亮度变换的枢轴参数，与Gamma一起看结果
Lift / Offset RGB0不添加整体灰阶偏移

900秒中途尝试为Gain200、Gamma4、Pivot1.5。不要把中途参数当成后期值。对比时保持相同Frame和Camera，只改这一组参数。

3 · Plane Object Properties

右键Plane001 → Object Properties。648.69秒显示Renderable及Primary Visibility开启；Secondary Visibility、Receive Shadows、Cast Shadows、Apply Atmospherics关闭。学习工程照此设置。平面尺寸Length350、Width500，Length/Width Segs均1；不是靠细分网格生成火焰形状。

4 · Background light pattern

1030秒Noise #25显示Coordinates = World XYZ，Size120，Regular，Low0/High1，Phase3，当前Frame100。工程将这一帧的Phase设为3；动画起始键尚未核实，未把它伪装成完整动画。两盏Gobo灯仍使用上一课学习工程的强度，最终强度与源片显示色彩管理尚待核对。

05:40 · Analyze the reference

课件将火焰拆成燃料、焰芯、焰尾、烟雾；观察下宽上窄、上端尖细、边缘不规则，以及火舌向上运动和断开的过程。这是课件的美术分析，不是材质参数表。

09:30 · Shape before color

课件展示三个部分：底亮顶暗的基础灰度、椭圆切割形成的火舌边缘、最后的颜色。复习时先检查轮廓，再检查透明度，最后检查颜色；这句检查顺序为补充学习建议，非视频逐字记录。

11:40 · Build each element over time

课件流程：先制作每个元素的逐帧形状，再设颜色，最后逐帧合成。图中分别显示焰芯和外焰，说明只做一层渐变无法交代所有元素的变化。

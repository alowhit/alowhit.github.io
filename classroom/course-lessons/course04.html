水波纹：先做断开的黑白圆环

原片：11月5日教学1.mp4。本节记录15个已阅读的时间点，包含后半段参数变化；不是全片逐帧核对完成。当前还没有这一套节点的已验收MAX工程。此前蓝白水圈与雨滴Torus水圈属于补充示范，不能代替本课逐值复刻。

先认清这节课做到了哪里

片尾展示的是黑白断环与颗粒，尚不是你参考图里的蓝色发光水纹。先检查黑白图形，后续再接颜色与透明度。不要在这一步靠加亮Emission掩盖图案差异。

Slate Material Editor 接线顺序

  1. 建立Gradient Ramp #6，使用Radial，把黑白色标交替排列成多个圆环。所有色标的位置尚未核全，请不要把示例位置22或94复制给所有色标。
  2. 建立Swirl #7和Waves #9。三张图分别接Composite #8的Layer 1、Layer 2、Layer 3，模式见下表。注意接Layer，不是Layer (Mask)。
  3. Composite #8 → Gradient Ramp的Source Map，Gradient Type选Mapped。老师把这个节点命名为SpFL，利用黑白色标筛选输入的亮暗值。
  4. SpFL → Composite #12的Layer 1；Cellular #11 → Layer 2；Gradient Ramp #14 → Layer 3。Swirl #13是中途试验，片尾已经断开。
  5. 本片中途将Composite #12接到Arnold Standard Surface的base_color观察黑白纹理。最终蓝色、Emission、Opacity接线需要下一课继续核对，不能凭这张片尾图补称老师数值。

每个参数到底在改什么

Radial让渐变按离中心的距离变化，所以黑白色标形成圈。Mapped / Source Map把输入图的亮度当作查色依据；改色标位置会改变哪些弧段保留下来。Multiply让黑色区域压暗底图。Cellular Size控制纹理尺度，Spread控制细胞颜色覆盖范围。Swirl Twist改变旋涡图案；这里没有证据表明它在扭曲模型。

补充：棚景的弯曲过渡怎样做出来

来源为《教学记录1.mp4》04:10–05:30的新增精确画面检查。04:10时已经有Line001、Line002、Loft001；这些画面不能证明从零绘制Spline及Loft的全部创建步骤。

  1. 04:20：Loft001已经是 Editable Poly，棚景呈转角形状。先认清对象和子对象层级，不要把对象名称Loft001当作当前仍有Loft修改器。
  2. 04:30：出现 Symmetry，画面可见Mirror Axis X，Slice Along Mirror和Weld Seam勾选、阈值0.01 cm。这是中途试调画面；04:40又回到Editable Poly层级。当前证据不足以把X轴写成最终对称设置。
  3. 04:50：进入 Editable Poly → Edge，选中2条边，打开Chamfer；初始Amount为0 cm、Segments为1。
  4. 05:00：Chamfer Amount显示100 cm，Segments仍显示1，面在选边周围展开成过渡带。此处是明确读到的中间值，不是已确认的最终分段数。
  5. 05:01–05:02：对话框清楚显示 Amount 100 cm、Segments 2。将分段从1改为2后，选边附近出现更多过渡面；05:02鼠标位于确认按钮附近，05:03对话框已关闭。
  6. 05:05–05:09：继续选择另一组边。05:07可见2条边被选中，05:08–05:09再次打开Chamfer，对话框仍为 Amount 100 cm、Segments 2。05:10对话框关闭，侧视图已有上下弧形过渡。这里记录的是两次可见操作值，不从最终网格反推参数。
  7. 05:20–05:30：老师旋转Perspective View检查转角、底部及背面。观察模型是否连贯，再继续材质步骤。

你应理解的操作：这里用的是多边形的 Edge / Chamfer；不是只调整材质就能把地面与墙的折角变圆。Amount决定过渡带的尺度，Segments参与决定分段；要在正确的边上操作。若直接打开最终Class2工程，棚景已经过这些编辑，不要再重复执行一次100 cm Chamfer。

本次补的是原片步骤与可读参数证据。可编辑的Class2棚景已包含在05源视口工程中；每个棚景中间状态的独立MAX重建仍待完成。

继续：Symmetry 与 Render Setup

  1. 05:55 · Symmetry：此时可直接读到 Mirror Axis = X、Flip = On、Slice Along Mirror = On、Weld Seam = On；两个 Threshold 都为 0.01 cm。对比04:30的试调状态，关键变化是 Flip 已勾选。此时棚景已镜像成完整宽度。前面的“不足以确认最终设置”仅针对04:30单独一帧；05:55提供了后续明确证据。
  2. 06:05 · 检查外观：取消选择后，Perspective View 显示粉色棚景、弯曲底部与侧边。此时没有选中对象，不能仅凭空白 Modifier 面板判断修改器已被删除。
  3. 06:15 · Render Setup：Renderer = Arnold；View to Render 指向第4个 Perspective 视口；Time Output = Single。Output Size 此时是 HDTV，Width = 1280、Height = 720、Image Aspect = 1.77778、Pixel Aspect = 1.0。这是该时刻的设置。
  4. 06:25–06:35 · 切换尺寸预设：老师展开 Output Size 列表，随后指向 Custom。不要因为列表里出现HDTV，就把整节课的输出都写成HDTV。
  5. 06:45 · Custom：此时清楚显示 Width = 640、Height = 480、Image Aspect = 1.333、Pixel Aspect = 1.0；Width 输入框正被选中。后续仍可能修改，故记录为06:45的检查点，而非最终交付尺寸。

操作用途：Symmetry 用另一半补齐模型，Flip 决定镜像保留的方向；Slice Along Mirror 在镜像平面处切分，Weld Seam 将接缝附近顶点焊接。先检查接缝和整体形状，再确认渲染哪个视口。Width / Height 决定输出图像的像素尺寸，改变它们不会自动创建 Camera。这一段的 View to Render 仍为 Perspective，不能写成已创建相机。

06:50–06:53 · 本段随后采用的尺寸：06:50先把 Width 改为800，Height暂时还是480；06:53再把 Height 改为400，此时 Image Aspect = 2.0、Pixel Aspect = 1.0。因此跟做这段操作应依次看到 640×480 → 800×480 → 800×400，不能停在06:45的中间状态。当前火球动画预览640×320保留相同2:1比例，但像素尺寸是补设的预览值，不是原片逐值复制。

棚景材质：Physical Material 的实际操作

来源《教学记录1.mp4》09:20–10:40。这里处理的是 Loft001 棚景，不是火球表面的特效 Shader。画面明确显示 Material #43 的类型为 Physical Material，位于 General 分类；Renderer 为 Arnold 是另一项设置。按老师这段步骤复现时，请保留这个材质类型。

  1. 选中 Loft001，在 Slate Material Editor 找到 Material #43。09:20–09:40老师展开 Preset 列表浏览不同预设；菜单中高亮某一项不等于已经采用它，不要照着鼠标经过的每个名称改一遍。
  2. 10:00的材质标题区域显示 Rubber（橡皮），Material Mode 为 Classic Advanced（经典高级）。之后老师继续手动修改参数，因此不能只选 Rubber 就认为做完了。
  3. 打开 Base Color 色块。10:20的颜色选择器显示 RGB 249 / 249 / 249、Hex F9F9F9；10:25进一步改成显示侧 RGB 250 / 250 / 250、Hex FAFAFA。同一画面另一列小数约0.957。逐值输入时要看清 Display / Scene 以及数值范围，不能把250直接填入0–1的小数输入框。
  4. 10:30颜色窗口已关闭，Reflection Roughness 显示 0.0；此前10:20–10:25还是0.63。10:40仍为0.0。将中间值和后续值分开记录。
Parameter10:30–10:40 可读值怎样理解
Base Weight1.0基础表面分量的权重。
Base Color10:25 Display RGB 250 / 250 / 250棚景接近白色；颜色以该帧颜色选择器为依据。
Base Roughness1.0这是基础漫反射部分的 Roughness，不是下面反射行的 Roughness。
Reflection Weight0.0该反射分量的权重为零；不要仅因 Reflection Roughness 为零就说棚景变成镜子。
Reflection Roughness0.0控制反射分量的粗糙程度，但还要结合 Reflection Weight。
Metalness / IOR0.0 / 1.52画面保留的金属度与折射率参数。
Transparency / Subsurface Scattering / Emission Weight均为0.0这里没有靠这些分量制作透明、次表面或发光效果。
Emission Luminance / Kelvin1500 cd/m² / 6500虽有这些数值，但 Emission Weight 为0；不能据此说棚景已开启自发光。

与已有工程的关系：保存工程的参数读取中，棚景同样是 Physical Material，Reflection Weight = 0、Reflection Roughness = 0、Base Roughness = 1。脚本报告的 Base Color 为约244.129，属于脚本读取的颜色表示，不能直接当作此处 Display RGB 250 的不一致证明；也不能未经颜色管理核对便宣称它们逐值等同。原片显示值和工程读取值分别保留。

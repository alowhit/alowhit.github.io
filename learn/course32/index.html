前半段：Quad → Arnold Cylinder → Photometric Cylinder

这几种是老师先后尝试的灯光方案，不能把参数混成一盏灯。本次补上前两种的可编辑学习工程；光度学灯阶段见下方新增实验。工程继承第31课的火焰材质与场景，镜头、火焰密度和曝光未完全匹配老师。

1 · Quad 阶段

选择第二盏 Arnold Light，在 Modify → Shape → Type 选择 Quad。80秒画面为 Quad X 485.6、Quad Y 100；到250秒变成 Quad X 528.6、Quad Y 135.5。Spread 1、Resolution 500、Roundness 0、Soft Edge 1、Intensity 1。

250秒没有完整展示 Exposure。学习工程的 Exposure 6、Rotation (70,0,0)°、Targeted Off 是补齐设置；Position (−0.856,−39.12,96.733) cm 来自80秒。因此这是组合学习场景，不能称为250秒逐项精确快照。

2 · 切换 Arnold Cylinder

300秒老师将同一盏灯的 Type 改成 Cylinder。初试 Radius 5、Height 476.6；350秒调整为 Radius 19.9、Height 522.2 cm，Intensity 1、Exposure 6、Normalize Energy Off、Targeted Off。位置为 (−0.856,−10.927,96.733) cm。300秒可见 Rotation (−107.631,−90,0)°，工程沿用此角度，350秒的精确角度未显示。

当前安装的 Max 界面也确认了 Cylinder 类型及 GPU 不支持提示；这些比较使用 CPU。切换 Type 后重新检查 Intensity 和 Exposure，本次脚本构建时曾发生重置，已修正后重新保存。

3 · 火焰平面 Object Properties

按400秒画面：Renderable On、Visible to Camera On、Visible to Reflection/Refraction Off、Cast Shadows Off、Receive Shadows Off。它们控制对象的渲染参与方式；黑色背景是否透明仍是材质问题。老师此时的渲染也有黑色矩形，本实验保留该阶段。

4 · 为什么数值相同，亮度仍不一样？

下面相同镜头、相同Frame100，依次关闭第二盏灯、启用Quad、换成Cylinder。当前Cylinder Exposure6使背景过亮；另存的观察版只把第二盏灯 Exposure降到2，不冒充老师数值。颜色RGB(255,100,0)为自选补齐，原片未打开精确颜色值。已有第一盏灯保持原样，旧Gobo修改器在本实验里禁用，避免后续课的滤镜影响早期灯形比较。

曝光控制的 Physical Scale 也会影响 Arnold 灯亮度；因此只复制灯的Exposure不能保证跨场景视觉一致。Autodesk：MAXtoA Lights

5 · 后面不是同一种圆柱灯

1000秒的 TPhotometricLight001：Cylinder Length520、Radius13、Intensity1500 cd、Shadow Samples32、Raytrace Bias0.2。这个光度学灯不是 Arnold Cylinder，也不是后面的 Cylinder001 + Mesh Light。下方已提供分时点光度学实验工程；未确认项目单独注明。

Photometric Light：三个实验时点

三份文件在现有 Max 窗口内构建、保存、重新打开并实际渲染。沿用之前的部分还原场景：它们是可编辑实验，不是老师镜头的精确复刻。旧 Arnold 第二盏灯关闭，第一盏灯保留。

1 · 创建 Target Light

Create → Lights → Photometric → Target Light。将 Light Distribution 设为 Uniform Spherical，Intensity Units 选 cd，输入 1500。600秒原片使用 D65 颜色预设；工程目前用 Kelvin6500 近似，不能称为相同预设。

2 · Cylinder，先13，再50

Shape/Area Shadows → Emit Light From 选 Cylinder。1000秒：Length520、Radius13 cm；1100秒：Length520、Radius50 cm。位置 X1.057、Y−11.436、Z106.699 cm。目标距离268.509来自600秒，学习版沿用；目标朝向及Roll90°为补齐值。

1000秒显示 Shadow Samples32、Raytrace Bias0.2、Max Quadtree Depth7。工程已设置可访问的Bias和Depth，Shadow Samples 尚未完成原生属性确认。MAXtoA对光度学灯存在限制，部分阴影参数不会用于Arnold渲染，不应把它们解释成Arnold AA Samples。Autodesk：光度学灯兼容说明

3 · Checker 与 Noise 不要混为同一个时点

1100秒可见 Advanced Effects → Projector Map 开启，插槽为 Checker #12。Checker在1000秒编辑器中采用 Environment → Screen。学习版按这个坐标设置连接Checker；精确投影外观尚未匹配。

1100秒的 Noise #13 仍是 Object XYZ、Size63.5、Low0、High1。1200秒变为 Explicit Map Channel1、Size0.2、Low0.4、High0.6、Regular、Phase0。此时画面没有露出最终Projector Map插槽，所以不能证明Noise已替换Checker。第三份工程把Noise留在Slate中供检查，保留此前Checker连接。

4 · Rectangle 与 Dimming

1200秒光源已经变成 Rectangle：Length520、Width61 cm。Dimming开启，Multiplier200%，基础Intensity1500 cd，界面结果为3000 cd。不要把200写成Intensity，也不要把它当作Arnold Exposure200。

Photometric Cylinder只允许Uniform Spherical分布；本节没有擅自把它改成Spotlight来制造投影效果。Autodesk：Photometric参数

渲染仅验证这些场景能执行。摄影机、背景、火焰密度、D65精确预设、Shadow Samples及排除列表仍有差异；不是完成全课或考核的证据。

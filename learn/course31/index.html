Fire layers: shape → detail → color

本节已核对下面13个原片时点，尚未逐帧完成。下方提供含补设值的可编辑MAX与分层渲染。这里记录的是各时间点真实显示的值，不把不同阶段的试验拼成一个“最终参数”。

先认识三件事

  1. Shape：先把火苗的黑白轮廓做出来。
  2. Detail：用Smoke产生另一张纹理，再经Mapped Gradient Ramp分成灰度层次，接入Composite。
  3. Color：最后用Mapped Gradient Ramp把灰度换成火焰颜色。颜色不能代替缺失的轮廓处理。

Smoke #7 → Gradient Ramp #8 Source Map
Gradient Ramp #8 ─→ Composite #9 Layer 2
Composite #9 ────→ Gradient Ramp #10 Source Map

07:50补核：Cellular #1和Gradient Ramp #5进入Composite #6，#6接到#2的Source Map。所有完整色标和最终材质插槽仍待继续核对。本图只画清楚可见的连接。

为什么之前的练习边缘偏软？

当前Course30练习把Cellular与噪波渐变的Multiply结果直接接到Emission Color；它缺少这里可见的后续Gradient Ramp和Composite处理。因此它只是中间纹理练习，不是老师完整火焰。缺少灰度重映射是边缘差异的候选原因，仍需在MAX中补齐并进行同条件渲染才能确认。

现在能看到完整主分支：Cellular #1与Gradient Ramp #5进入Composite #6；#6输出接Gradient Ramp #2的Source Map；#2再进入Composite #3 Layer1，Gradient Ramp #4进入Layer2。这是当前Course30练习缺失的后续连接。

已修正的实际错误：Interpolation

第一次构建时，名为Solid的旧模板实际显示Ease In。通过Slate界面直接把Gradient Ramp #2改为Solid，再用这个经过界面确认的原生节点建立#8。修正后重新保存、打开并渲染。节点名称不等于实际参数，必须检查右侧Interpolation下拉框。

每一步到底做什么？

在Max里跟着看

  1. 打开下载的MAX。按M进入Slate Material Editor，用Pick Material from Object拾取Plane001的材质。
  2. 找到02_Solid_Threshold，双击节点，展开Gradient Ramp Parameters，确认Gradient Type=Mapped、Interpolation=Solid。
  3. 先看Source Map的连线：它应来自06_Multiply，而不是直接来自Cellular。
  4. 沿输出依次找到03_Darken_Height、09_SoftLight_Detail和10_Fire_Color。改变颜色前，先确认黑白轮廓。
  5. 若要自己比较，先另存副本、关闭Auto Key，把同一个材质的Emission Color Map临时接到各阶段输出；保持Frame100和Camera不变。最后恢复10_Fire_Color。

已有详细教学 · 按本课原视频整理

细胞主轮廓与Smoke细节分别经过渐变重映射，再合成、映射为黑红橙黄白火焰。教师界面中的Fire是物理材质；换成Arnold Standard Surface必须标为兼容适配。

以下内容来自旧版补习页已经保存的核对记录。本次按视频文件名接入，保留时间点、补充值和未知项；没有把整合网页计为新的逐帧核对或MAX完成。数值可能属于中间试验，请结合时间点与状态看。

操作步骤

1. 高度遮罩变化

对Gradient Ramp #5的噪声和相位进行实验。

2. 加入Smoke

Smoke白黑噪声纵向拉伸，预览为柔和流线。

3. 主轮廓与细节分支合成

Cellular阈值轮廓加竖向Ramp，Smoke经另一个Ramp细化，两支进入Composite #9。

4. 把Smoke分段

Gradient Ramp #8使用Map和Solid，黑色旗标位置8，形成硬分段明暗细节。

5. 缩小Smoke细节

Size改为15、TilingY0.2、Exponent0.09，保留5次迭代。

6. 映射火焰色带

Composite #9作为Gradient Ramp #10的Source，将灰度转换为火焰颜色。

7. 火焰颜色预览

可看到黑红橙黄配色；颜色旗标还在调整，不能从缩略色带猜成精确RGB。

8. 继续高度渐变实验

竖向Ramp V tiling4、noise amount0.05，当前渲染仍在变化。

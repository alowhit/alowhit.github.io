课堂2：布灯、材质比较与程序贴图模拟高光

全片89分53秒。本轮检查45张两分钟间隔图、39个精确时点（另复查49:00–53:00的17张15秒间隔图、56:00–89:30的68张30秒间隔图）和原有5张截图；不是逐帧核对完成。下列步骤覆盖主要教学顺序，未确认的混合模式、曲线控制点和中途值继续保留为待核对。

1 · 00:00–11:00：从背景开始放三盏 Photometric 灯

  1. 延续上一课的 Loft 背景。进入 Create → Lights → Photometric 创建灯。
  2. 03:00先出现 Free Light，Intensity 1500 cd，颜色选D65标准白，Kelvin输入框未启用。不要照抄灰色3600当作生效色温。
  3. 随后变为带 Target 的矩形发光面，放在背景两侧，Target 朝向主体区域。07:11左灯正在改尺寸，Length 279.38、Width 61，此为中途值。
  4. 约11:00增加前上方横向大灯。此时 Width 1000，随后改成1500；19:00可见最终这一阶段 Length 250、Width 1500、Shadow Samples 64。

灯的 Position 决定它在哪里；Target 决定朝哪里。Rectangle 的 Length / Width 决定发光面尺寸，对球上的高光形状也有影响。

2 · 约11:00–24:00：放 GeoSphere 并检查 Arnold

主球使用 GeoSphere，课堂25:00确认 Radius 150、Segments 64、Icosa、Smooth On、Generate Mapping Coords On。随后复制为两球对比；保存版两球位置分别为(−329.182,136.943,291.729)与(0.535714,136.943,291.729)。课堂渲染使用 viewport_camera，本轮另加固定 Camera 便于重复渲染，不宣称匹配原透视视口。

19:00 Render Setup 的 Compatibility Mode = 3ds Max Maps Support，Camera AA = 3，Diffuse / Specular / Transmission / SSS / Volume Indirect Samples = 2；Diffuse / Specular Ray Depth = 1，Transmission Depth = 8，Volume Depth = 0。后续样本设置继续改变，视频RenderView的4/3/...不是这一时点的同一组值。

3 · 约25:00–37:00：先比较真实反射

创建 Physical Material，课堂25:00可见 Base Weight 1、Reflection 1、Reflection Roughness 0、Metalness 0、IOR 1.52、Transparency 0。Emission Weight虽然显示1，但Emission Color为黑，因此不能据此说球正在明显发光。复制材质作为无反射对照；33:00金属材质 Metalness = 1，球上出现灯与环境的反射。

打开下面的01工程：左球是 Metalness 1、Reflection 1、Roughness 0；右球 Reflection 0。两球共用同一场景灯光。灰色RGB128为补充实验值，灯与背景为后期保存状态，镜头为补充设置。因此这是课堂原理的重建对比，不是33:00画面逐像素复制。

4 · 约37:00–47:00：切换到 Emission Color 模拟图案

  1. 另建模拟材质，Base Color黑、Reflection 0、Metalness 0、Transparency 0。37:00可见 Emission 1、Luminance1500、Kelvin6500。
  2. 把 Noise #10 接到 Emission Color。41:00仍是 Object XYZ、Size0.2，图案尺度非常小。
  3. 41:30清楚显示 Luminance 已降到100 cd/m²；早先1500不能沿用到这一阶段。
  4. 45:00切换 Explicit Map Channel 1，Tiling (1,0.2,1)，Noise Type Fractal，Size0.2、Low0.4、High0.6、Levels3、Phase0。

坐标系统决定Size如何被解释，所以 Object XYZ 的0.2与UV的0.2不能只看数值相同。Tiling的V变小使图案沿V拉长。下面02工程已修正为 Luminance 100 cd/m²（41:30画面确认），配合45:00的Noise值。原学习档误用了37:00的1500，发光强度高了15倍，导致图案过亮。修正后已保存、重新打开读回100并重新渲染。仍是两个时点的已知参数组合，镜头与后期保存灯光不代表完全匹配45:00；当前两张为低采样学习预览，并非最终交付画质。

5 · 约49:00–69:00：用 Falloff 分别控制轮廓和高光

Noise #10 ─────────────→ Composite #12 / Layer 1
Falloff #11（边缘亮）──→ Composite #12 / Layer 2
Falloff #13（亮斑）────→ Composite #12 / Layer 3
Composite #12 ─────────→ Emission Color

49:00 Falloff #11 是 Perpendicular / Parallel，Viewing Direction (Camera Z-Axis)，Front黑、Side白。开始是直线Mix Curve，53:00曲线压低中间值，使亮部主要留在轮廓。59:00另一个Falloff #13改为 Direction = Object，Object = Box001，Front白、Side黑；通过参考物体位置和曲线调整亮斑。

作用区别：真实反射计算场景反射；这里把黑白图案当作发光颜色显示。像高光的亮斑可以由Falloff画出来，但不等于真实灯光反射。新增核对：49:15时 Layer 1（Noise）和 Layer 2（Falloff）都为 Normal、Opacity 100%；50:00时 Layer 2 已改为 Multiply（相乘）、Opacity 100%，Layer 1 仍为 Normal、100%。不要把最初的 Normal 当作最终设置。Multiply 将两层灰度相乘：Falloff 的黑色区域压暗 Noise，白色区域保留 Noise，因此这里是用 Falloff 限制亮部。后续六层的已核对模式、Opacity与原生工程见下方07版；此处记录的是早期三层状态。

69:00 Noise #10调整为 Fractal、Size0.1、Low0.3 / High0.75、Tiling (1.5,0.2,1)，Color1也从黑色改为灰色。它已经不是45:00那组值。

按课堂顺序搭建：61:30还是三层，Layer 3是亮斑Falloff，Lighten、100%。75:00在Noise后插入Marble，成为Layer 2（Multiply、70%），轮廓与亮斑顺延为Layer 3 / 4；此时亮斑已为50%。再插入Cellular后，78:30显示Marble70%、Cellular正在调至50%，79:30两者都为40%。最后加入Smoke成为Layer 6。不要一直把“Layer 2”理解成同一个节点：插层后编号会改变。

Smoke的后期值也不同：87:45确认 Explicit Map Channel 1、Tiling (1,1,1)、Offset (0,0,0)、Size 0.5、Iterations 5、Exponent 1.5、Phase 0；Color 1接Falloff #18，Color 2黑。85:00的101.6只是较早阶段的Size，不能拿它代替87:45的0.5。

理解这些模式：Multiply让黑色区域压暗前面已有的图案；Lighten逐通道保留较亮的值，50% Opacity让这一层只参与一半；Screen让Smoke层提亮底下结果，其中黑色不改变底层。先按表设置，再分别关闭一层对比，才能看出各层贡献。

查看逐层证据记录。以上补齐了关键时点的层顺序、混合模式和强度，六层MAX的最新状态见本节末尾；全部颜色、Mix Curve控制点及后续变化仍待核对。

04 · Mix Curve 界面实验版

轮廓 Falloff #11 已通过 Max 界面修改曲线，另存并重开后重新渲染。此版把响应压到右端附近，是操作验证与近似实验，尚未匹配老师精确控制点；Highlight #13 仍为直线。

  1. 双击轮廓 Falloff，展开 Mix Curve。
  2. 选择 Add Point，点在曲线上；切换 Move 后拖动控制点。单凭添加后外观仍为直线，不能判断操作失败。
  3. 比较03与04。当前后续 Lighten 和 Screen 层仍会提亮暗部，所以改轮廓曲线并不保证最终合成马上出现窄亮边。继续分别检查亮斑与Smoke层。

05 · 修正 Falloff Direction，并逐层看效果

在当前 Max 2024 中实际核对发现：旧03、04学习档的 Highlight #13 设置成了 Camera X-Axis，并非老师63:00的 Object。05版已修正为 Falloff Direction = Object，Object = Box001，保存重开后读回 direction=3。旧文档把1描述为Object，但当前界面的1是Camera X-Axis，学习时以界面名称和当前版本验证为准。

05保留04的近似轮廓曲线；亮斑曲线仍是直线，尚未达到老师前段迅速上升、随后趋平的形状。Box001位置仍来自后期原生保存档，不能宣称与63:00完全一致。此处三图是同场景诊断对照，不是老师依次保存的三个阶段。实际对照已确认：前四层保留暗球和细亮边；开启Layer 5后大部分球面变亮，Layer 6再进一步提亮。因此应优先核对Highlight曲线与Box001位置，而不是继续整体降低Emission。

  1. 打开 Composite #12，先关闭 Layer 5 与 Layer 6，查看轮廓层之前的结果。
  2. 开启 Layer 5，保持 Layer 6关闭，观察亮斑层的贡献。

Particle Flow · Scale and event loop

已检查 87 张约每 20 秒一张的画面，并列出下面 21 张原分辨率参数截图。这是步骤核对，不是全片逐帧验收；本节已有原生循环 MAX 学习档；最终渲染验收未完成。

先看懂连接

Event 003: Birth + Position Object + Shape Instance
  Split Amount 50% → Event 004: Scale → Send Out ┐
  Send Out (All)  → Event 005: Scale → Send Out ┴→ Event 006
Event 006: Scale → Scale Test 001 → Event 007
Event 007: Scale → Scale Test 002 → Event 008
Event 008: Scale → Scale Test 003 → Event 007

Scale 改变粒子的大小。Scale Test 检查大小是否越过门槛，满足条件后沿线进入下一个 Event。这里后半段用来交替变小、变大。先照截图接线，再逐个检查参数；不要只复制节点名称。

为什么老师的粒子会换颜色？

截图里的各个 Event 有不同的 Display 颜色。颜色帮助看出粒子当前进入哪个 Event，不能据此认定老师已做出相同颜色的 Arnold 材质。

不要混用中途值和最终值

Scale Test 的门槛先后出现 104%、150%、80%、90%，后面又增加 Variation。下面按视频时间保留这些变化。已有 Test7 工程的参数记录与本片结尾不完全一致，不将它标作本节逐值复刻。

02:10 · Initial scale variation

Scale 001: Inherit Once，XYZ 100%，Variation 10/20/20%，Seed 12345。GeoSphere001 Radius 30 cm，Segments 2，Icosa，Z 50 cm。

03:50 · First variation edit

Scale 001: XYZ 100%，Variation 改为 10/20/30%，Seed 16451。

04:50 · Split Amount

Event 003 中加入 Split Amount，Particle Fraction 50%，Seed 12345。Birth 摘要仍为 −1 / Total 42。

05:30 · First branch

Split Amount 接 Event 004。此时 Scale 001 为 Inherit Once，XYZ 100%，Variation 10/20/30%，Seed 16451。这是中途值。

06:30 · Second branch

Event 003 的 Send Out (All) 接 Event 005；Split Amount 接 Event 004。此时 Scale 002 为 Overwrite Once，XYZ 100%，Variation 0。

07:30 · Branch scale edit

Event 005 中 Scale 001: Inherit Once，XYZ 100%，Variation 30/20/10%，Constrain Proportions 两项均关闭，Bias None，Absolute Time，Seed 16451。

08:50 · Other branch scale

Event 004 中 Scale 002: Inherit Once，XYZ 130%，Variation 50/70/10%，两项 Constrain Proportions 关闭，Bias None，Absolute Time，Seed 12345。

10:10 · Merge events

Event 004 / 005 各用 Send Out (All) 接到 Event 006。Scale 002 已改为 Inherit Once，XYZ 130%，Variation 50/70/10%。Display 006 此刻是 Crosses，所以不能仅凭视口判断粒子模型消失。

11:30 · Two scale operators

Event 006 包含 Scale 003 (Inherit Once)、Scale 004 (Overwrite Once) 和 Display Geometry；此刻 Scale 004 为 XYZ 100%，Variation 0。

12:30 · Keep inherited shape

Scale 003: Inherit Once，XYZ 100%，Variation 0，Constrain Proportions 两项开启，Bias None，Absolute Time，Seed 12345。

13:30 · Continuous growth

Scale 004 改为 Relative Successive，XYZ 101%，Variation 0，Sync By Absolute Time。这是连续变大的阶段。

14:50 · Add a size gate

Scale Test 001 接 Event 007；当时摘要 Scale >104%。Event 007 已放 Scale 005 (Relative Successive)，当前 XYZ 100%。后续老师继续改值，不能把此处当结尾。

15:00 · Shrink continuously

Scale 005: Relative Successive，XYZ 99%，Variation 0，Constrain Proportions 两项开启，Bias None，Absolute Time，Seed 12345。与 13:30 的 101% 长大方向相反。

15:10 · Maximum axis test

Scale Test 001: Scale，Axis Maximum，Greater Than，150%，Variation 0，Absolute Time。后续 Variation 改成 30%。

16:30 · Prepare the next event

Scale Test 001 已变成 >150%；Event 007 中 Scale Test 002 此时 <80%，新建的 Event 008 还没接好。

16:46 · Regrowth scale verified

Scale 007: Relative Successive，XYZ 101%，Variation 0，Constrain Scale 关闭、Constrain Variation 开启，Bias None，Absolute Time，Seed 12345。已找到具体数值，不需要自行补齐。

16:55 · Display the third event

老师把 Display 008 从 Crosses 改成 Geometry；Event 008 已有 Scale 007 (Relative Successive)。本图未展示 Scale 007 的具体 XYZ，不能仅凭名称复制数值。

17:20 · Connect back

老师从 Scale Test 003 的输出拖出连接线，随后接回 Event 007。此刻 Test 003 为 Maximum / Greater Than / 150%，Variation 0；后续改成 30%。

18:10 · Close the loop

Event 007 的 Scale Test 002 接 Event 008，Event 008 的 Scale Test 003 回接 Event 007。Scale Test 002 此时 Axis Average、Less Than、90%、Variation 0。

18:50 · Threshold variation

三个 Test 的摘要已分别为 >150±30%、<90±30%、>150±30%；Test 003 面板确认 Maximum，150%，Variation 30%。

28:30 · Final visible thresholds

结尾 Scale Test 003 面板：Type Scale，Axis Maximum，Greater Than，Test Value 150%，Variation 30%，Sync By Absolute Time，Seed 12345。节点摘要显示 Test 001 >150±30%，Test 002 <90±30%。Test 001/002 的 Axis 不能从该结尾画面确认。

Scale 007 数值和实际粒子循环已补证。仍待核对 Test 001/002 结尾 Axis；动画模型副本的完整渲染已完成，原生循环PF直接渲染仍未通过。

渲染检查记录：本机 GUI 在直接渲染这个循环 PF 时出现 Call stack overflow 并退出；原因仍在排查。已保存的原生工程与逐帧粒子数据保留，不能把运行数据通过当作渲染通过。已制作独立的几何体动画副本并完成101帧GUI渲染，见本页动画预览；原生循环PF的直接渲染故障仍未解决。
